# Chapter 4. Relational Encodings of Process and Directive Ontologies in Laboratory Measurement Systems

Laboratory information management systems require explicit linkages between process executions, produced information entities, and directive constraints such as ISO 27001 clauses. This chapter presents four tables that instantiate the supplied OWL axioms as a minimal, cross-joinable schema. The tables capture laboratory runs that produce measurements, measurements produced by runs, basic descriptive states, and subclass relations that attach ISO 27001 clauses to laboratory processes. All column values are drawn from realistic instances of biodiesel analysis and radio-astronomy equipment calibration under information-security controls.

## 1. Schema Overview and Axiom Mapping

The schema directly projects the four axioms. Primary keys are uniformly named id. The single foreign-key constraint implements the existential restriction in axiom 2. Cross-table navigation therefore proceeds either by id equality on the foreign key or by value equality on the x columns that represent shared class references.

### 1.1 Table t_labrun_produces_measurement

This table embodies axiom 1: each row asserts that a laboratory process class produces a descriptive information content entity. Column id is the primary key; column x holds the process class identifier.

```sql
CREATE TABLE t_labrun_produces_measurement (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

### 1.4 Table t_iso27001_clause_subclass

This table embodies axiom 2: each row asserts that a laboratory process class is a subclass of a directive information content entity that satisfies a particular ISO 27001 clause. Column id is the primary key; column y is a foreign key referencing t_labrun_produces_measurement.id.

```sql
CREATE TABLE t_iso27001_clause_subclass (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_labrun_produces_measurement(id)
);
```

## 2. Cross-Join Demonstration

A multi-hop query can recover the ISO 27001 clause attached to the measurement produced by a given laboratory run. Consider the question: “Which ISO 27001 clause governs the calorific-value measurement produced by the biodiesel process LR01?”

The join path traverses t_labrun_produces_measurement → t_iso27001_clause_subclass on id = y, then follows the shared x value to locate the corresponding measurement in t_measurement_produced_by_run. The result row is:

LR01 | BiodieselCalorificProcess | ISO01 | A.12.4.1EventLogging | M01 | CalorificValueICE

The same pattern extends to any other laboratory run present in the four tables.

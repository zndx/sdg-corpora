# Chapter 4: Relational Representation of Laboratory Processes and Directive Subclasses

This chapter presents a minimal relational schema that encodes four ontological axioms governing laboratory runs, measurements, and ISO 27001 directive classifications. The schema is grounded in a laboratory information management setting where biodiesel property determinations are performed under documented compliance clauses. Four tables are defined; each table header is preceded by a statement of the axiom it materializes, the primary-key and foreign-key constraints, and one example mental cross-join.

## 1 Axiom Embodiment and Table Definitions

### 1.1 Laboratory Run Producing Measurement
Axiom 1 states that a laboratory run is a process that produces a descriptive information content entity. The table t_labrun_produces_measurement therefore stores the run identifier together with the class of the produced entity. Column id is the primary key; column x references the measurement class that the run yields. A reader can join this table to t_measurement_produced_by_run on x to recover the inverse produced-by relation.

```sql
CREATE TABLE t_labrun_produces_measurement (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

| id   | x                          |
|------|----------------------------|
| LR01 | ViscosityResult            |
| LR02 | CalorificValueResult       |
| LR03 | CetaneNumberResult         |
| LR04 | DensityResult              |
| LR05 | FlashPointResult           |
| LR06 | AcidValueResult            |

### 1.2 ISO 27001 Clause Subclass
Axiom 2 states that a directive information content entity is a subclass of an ISO 27001 clause. The table t_iso27001_clause_subclass therefore records the subclass identifier, the directive class, and the foreign key to the laboratory run that produced the evidence for that clause. Column id is the primary key; column y is a foreign key referencing t_labrun_produces_measurement.id. A reader can join on y to retrieve the measurement class that substantiates each clause.

```sql
CREATE TABLE t_iso27001_clause_subclass (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_labrun_produces_measurement(id)
);
```

| id     | x                       | y    |
|--------|-------------------------|------|
| CL01   | A.12.4.1                | LR01 |
| CL02   | A.12.4.2                | LR02 |
| CL03   | A.12.4.3                | LR03 |
| CL04   | A.14.2.1                | LR04 |
| CL05   | A.14.2.7                | LR05 |

### 1.3 Measurement Produced by Run
Axiom 3 states that a descriptive information content entity is produced by a laboratory process. The table t_measurement_produced_by_run therefore stores the measurement identifier together with the class of the producing run. Column id is the primary key; column x references the run class. A reader can join this table to t_labrun_produces_measurement on x to close the produces/produced-by cycle.

```sql
CREATE TABLE t_measurement_produced_by_run (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

| id    | x                          |
|-------|----------------------------|
| MR01  | ViscosityRun               |
| MR02  | CalorificValueRun          |
| MR03  | CetaneNumberRun            |
| MR04  | DensityRun                 |
| MR05  | FlashPointRun              |
| MR06  | AcidValueRun               |

### 1.4 Basic State Descriptor
Axiom 4 states that a descriptive information content entity may exist without further subclass restriction. The table t_state_basic therefore stores the state identifier together with its class. Column id is the primary key. This table supplies leaf values that can be referenced by any of the preceding tables when only a descriptive entity is required.

```sql
CREATE TABLE t_state_basic (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

| id    | x                     |
|-------|-----------------------|
| SB01  | SampleReceived        |
| SB02  | EquipmentCalibrated   |
| SB03  | ResultValidated       |
| SB04  | ReportIssued          |
| SB05  | ClauseEvidenceStored  |
| SB06  | AuditTrailComplete    |

## 2 Cross-Join Demonstration

To recover the ISO 27001 clause that governs the calorific-value measurement produced by laboratory run LR02, the following mental join is performed. First locate LR02 in t_labrun_produces_measurement to obtain x = CalorificValueResult. Next locate the row in t_iso27001_clause_subclass whose y equals LR02, yielding CL02 and x = A.12.4.2. Finally confirm via t_measurement_produced_by_run that MR02 references the same run class. The joined row is therefore (LR02, CalorificValueResult, CL02, A.12.4.2, MR02).

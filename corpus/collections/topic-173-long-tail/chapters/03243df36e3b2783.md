# Laboratory Measurement Processes in LIMS

This chapter defines four tables that instantiate the supplied OWL axioms within a biodiesel testing laboratory. The tables record laboratory runs that generate descriptive measurement entities, link those runs to ISO 27001 control clauses, and capture the resulting information content entities under a controlled vocabulary.

## 1 Schema Structure and Axiom Mapping

The relational design follows the slot types of the four axioms exactly. Primary keys are synthetic identifiers; the single foreign-key column implements the existential restriction expressed by axiom 2.

### 1.1 t_labrun_produces_measurement

Axiom 1 is realized by this table: each row asserts that an individual laboratory run (X) is a bfo:0000015 process that produces a descriptive information content entity. Column id is the primary key; column x holds the class name of the run.

| id | x |
|----|--------------------------|
| LR001 | CetaneDeterminationRun |
| LR002 | CalorificValueRun |
| LR003 | ViscosityMeasurementRun |
| LR004 | DensityDeterminationRun |
| LR005 | FlashPointRun |
| LR006 | AcidNumberRun |

### 1.2 t_iso27001_clause_subclass

Axiom 2 is realized by this table: each row states that an information-security directive (X) is a subclass of cco:DirectiveICE that references a specific ISO 27001 clause (Y). Column id is the primary key; column y is a foreign key referencing t_labrun_produces_measurement.id.

| id | x | y |
|----|---------------------|-------|
| IC001 | A.12.4.1 | LR001 |
| IC002 | A.14.2.8 | LR002 |
| IC003 | A.12.4.1 | LR003 |
| IC004 | A.9.4.2 | LR004 |
| IC005 | A.12.4.3 | LR005 |
| IC006 | A.14.2.8 | LR006 |

### 1.3 t_measurement_produced_by_run

Axiom 3 is realized by this table: each row asserts that an individual (X) is a cco:DescriptiveICE produced by a laboratory process. Column id is the primary key; column x names the measurement class.

| id | x |
|----|---------------------|
| ME001 | CetaneNumberValue |
| ME002 | GrossCalorificValue |
| ME003 | KinematicViscosity |
| ME004 | DensityAt15C |
| ME005 | FlashPointPMCC |
| ME006 | TotalAcidNumber |

### 1.4 t_state_basic

Axiom 4 is realized by this table: each row asserts that an individual (X) is a cco:DescriptiveICE representing a sample state. Column id is the primary key; column x names the state class.

| id | x |
|----|------------------|
| ST001 | ReceivedState |
| ST002 | PreparedState |
| ST003 | AnalyzedState |
| ST004 | ArchivedState |
| ST005 | RejectedState |
| ST006 | RetainedState |

## 2 Cross-Join Demonstration

To retrieve the ISO 27001 clause that governs the laboratory run producing a given measurement, join t_iso27001_clause_subclass to t_labrun_produces_measurement on y = id and then conceptually align the resulting x values with rows in t_measurement_produced_by_run.  

Example query path: start with ME001 (CetaneNumberValue). Its producing run is LR001 (CetaneDeterminationRun). LR001 is referenced by IC001, whose clause is A.12.4.1. The joined row is therefore (ME001, CetaneNumberValue, LR001, CetaneDeterminationRun, IC001, A.12.4.1).

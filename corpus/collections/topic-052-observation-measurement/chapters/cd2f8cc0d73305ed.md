# Compliance Modeling for Artifacts and Directives

This chapter defines a relational representation of five ontology axioms that capture tax identifiers on artifacts, minimum-attribute descriptive claims, ISO 27001 clause directives, attribute-set cardinality, and priced artifacts. The schema supports cross-table joins that resolve multi-hop queries such as “which priced product satisfies an ISO 27001 clause asserted by a claim whose attribute references a given tax identifier.”

## 1 Schema Overview and Domain Grounding

The domain is information-security compliance documentation for automotive vision-system components. Each table directly implements one axiom. Primary-key columns uniquely identify individuals; foreign-key columns enforce the existential restrictions stated in the axioms. All literal values are drawn from registration-form and disclosure patterns typical of supplier and professional-society documentation.

## 3 Cross-Join Demonstration

Question: “What is the ISO 27001 clause and price associated with the artifact whose tax identifier is referenced by claim-01?”

Step 1. Start at t_outlier_claim_min_one_attribute where id = claim-01; read y = tax-01.  
Step 2. Join to t_schemaorg_org_taxid on id = tax-01; read x = VeoneerAB.  
Step 3. Join t_iso27001_clause_subclass on y = claim-01; read x = InformationSecurityPolicy.  
Step 4. Join t_schemaorg_product_price on y = claim-01; read x = VisionControllerUnit.

Result row: (VeoneerAB, InformationSecurityPolicy, VisionControllerUnit).

# Chapter 4. Relational Embodiments of Compliance Ontologies

This chapter specifies five tables that realize the slot structures of five OWL axioms. The tables record organizations identified by tax identifiers, descriptive claims carrying attribute sets, ISO 27001 clause references, minimal attribute sets, and priced artifacts. All foreign-key relationships are confined to the five schemas supplied by the axioms; every row satisfies the corresponding Manchester subsumption.

## 1. Schema Realization

The five tables are presented in the deterministic column order defined by each axiom. Primary keys are single-column identifiers. Foreign keys enforce the directed references stated in the axiom comments. Each table is preceded by a statement of the axiom it embodies and one example mental cross-join.

### 1.1 t_outlier_claim_min_one_attribute

Axiom 2 states that every descriptive information content entity possesses at least one attribute set. The table therefore stores the pair (X, Y) where X names the claim and Y references an attribute set identifier. Column id is the primary key. Column y is a foreign key into t_schemaorg_org_taxid, closing the mutual reference required by the axiom pair.

```sql
SELECT claim.x, tax.x
FROM t_outlier_claim_min_one_attribute claim
JOIN t_schemaorg_org_taxid tax ON claim.y = tax.id;
```

### 1.2 t_schemaorg_org_taxid

Axiom 1 states that an artifact carries a tax identifier. The table stores the pair (X, Y) where X names the organization and Y references the descriptive claim that records the identifier. Column id is the primary key. Column y is a foreign key into t_outlier_claim_min_one_attribute.

```sql
SELECT org.x, claim.x
FROM t_schemaorg_org_taxid org
JOIN t_outlier_claim_min_one_attribute claim ON org.y = claim.id;
```

### 1.3 t_iso27001_clause_subclass

Axiom 3 states that a directive information content entity is annotated with an ISO 27001 clause. The table stores the pair (X, Y) where X names the directive and Y references the descriptive claim that carries the clause text. Column id is the primary key. Column y is a foreign key into t_outlier_claim_min_one_attribute.

```sql
SELECT dir.x, claim.x
FROM t_iso27001_clause_subclass dir
JOIN t_outlier_claim_min_one_attribute claim ON dir.y = claim.id;
```

### 1.4 t_attribute_set_min_one

Axiom 4 states that a descriptive information content entity possesses at least one designative attribute. The table therefore records only the claim identifier X. Column id is the primary key; no foreign key is present.

```sql
SELECT attr.x
FROM t_attribute_set_min_one attr;
```

### 1.5 t_schemaorg_product_price

Axiom 5 states that an artifact carries a price. The table stores the pair (X, Y) where X names the priced product and Y references the descriptive claim that records the price value. Column id is the primary key. Column y is a foreign key into t_outlier_claim_min_one_attribute.

```sql
SELECT prod.x, claim.x
FROM t_schemaorg_product_price prod
JOIN t_outlier_claim_min_one_attribute claim ON prod.y = claim.id;
```

## 2. Cross-Join Demonstration

Consider the multi-hop question: which priced product is supplied by the organization whose tax identifier is recorded under the descriptive claim that also carries ISO 27001 clause A.12.1.1? The path traverses t_schemaorg_product_price → t_outlier_claim_min_one_attribute → t_iso27001_clause_subclass → t_schemaorg_org_taxid.

Execution yields the joined row:

- product.x = "ExaminationFormPrintService"
- org.x = "VeoneerUpdate"
- claim.x = "ClaimPrintVendor2020"
- clause.y = "A.12.1.1"

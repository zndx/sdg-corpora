# Chapter 7: Artifact Taxonomies and Descriptive Compliance Claims

This chapter presents five tables that realize the slot structures of five OWL axioms. The tables record organizations, compliance claims, ISO 27001 clauses, attribute sets, and product prices. Primary-key and foreign-key columns implement the existential restrictions stated in the axioms, permitting two- and three-table joins that recover multi-hop facts such as the tax identifier of the organization associated with a priced product whose claim cites a given ISO clause.

## 1. Schema Organization and Tax Identifier Records

Axiom 1 states that an artifact class carries a tax identifier. Table t_schemaorg_org_taxid therefore stores the pair (x, y) where x is an organization class and y is a tax-identifier class. Column id is the primary key; column y is a foreign key into t_outlier_claim_min_one_attribute, allowing a claim to be joined directly to the organization that asserts the tax identifier.

```sql
CREATE TABLE t_schemaorg_org_taxid (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_outlier_claim_min_one_attribute(id)
);
```

| id | x | y |
|----|---|---|
| tax001 | org:AcmeSensors | claim004 |
| tax002 | org:BioPack | claim001 |
| tax003 | org:MedLabel | claim002 |
| tax004 | org:SecureTag | claim005 |
| tax005 | org:ThermoUnit | claim003 |

## 2. Outlier Descriptive Claims

Axiom 2 asserts that a descriptive information content entity possesses at least one attribute set. Table t_outlier_claim_min_one_attribute therefore records the pair (x, y) where x is the claim class and y is an attribute-set class. Column id is the primary key; column y is a foreign key into t_schemaorg_org_taxid, closing the mutual reference required by the paired axioms.

```sql
CREATE TABLE t_outlier_claim_min_one_attribute (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_schemaorg_org_taxid(id)
);
```

## 3. ISO 27001 Clause Subclasses

Axiom 3 states that a directive information content entity is annotated with an ISO 27001 clause. Table t_iso27001_clause_subclass therefore stores the pair (x, y) where x is the directive class and y is a claim class. Column id is the primary key; column y is a foreign key into t_outlier_claim_min_one_attribute, enabling retrieval of every clause attached to a given claim.

```sql
CREATE TABLE t_iso27001_clause_subclass (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_outlier_claim_min_one_attribute(id)
);
```

## 4. Attribute-Set Cardinality

Axiom 4 requires every descriptive information content entity to possess at least one designative information content entity as attribute. Table t_attribute_set_min_one therefore records only the claim class x. Column id is the primary key; no foreign-key column is present because the axiom imposes an existential restriction internal to the claim.

```sql
CREATE TABLE t_attribute_set_min_one (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

| id | x |
|----|---|
| attr001 | claim:TaxValidity |
| attr002 | claim:BatchTrace |

## 5. Product Price Assertions

Axiom 5 states that an artifact class carries a price. Table t_schemaorg_product_price therefore stores the pair (x, y) where x is a product class and y is a claim class. Column id is the primary key; column y is a foreign key into t_outlier_claim_min_one_attribute, permitting price lookup via the same claim that carries tax and clause data.

```sql
CREATE TABLE t_schemaorg_product_price (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_outlier_claim_min_one_attribute(id)
);
```

| id | x | y |
|----|---|---|
| price001 | product:SN-400 | claim004 |
| price002 | product:BP-200 | claim001 |
| price003 | product:ML-90 | claim002 |
| price004 | product:ST-55 | claim005 |
| price005 | product:TU-300 | claim003 |

## 6. Cross-Table Retrieval Example

To recover the tax identifier and ISO clause for the product whose price is asserted under claim004, join t_schemaorg_product_price to t_outlier_claim_min_one_attribute on y = id, then to t_schemaorg_org_taxid on y = id, and finally to t_iso27001_clause_subclass on y = id. The resulting row is:

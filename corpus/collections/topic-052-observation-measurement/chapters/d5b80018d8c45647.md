# Modeling Compliance Artifacts and Descriptive Claims

This chapter defines a minimal relational schema that materializes five OWL axioms governing artifacts, descriptive information content entities, and directive information content entities. The schema supports cross-table joins that resolve multi-hop queries over tax identifiers, attribute sets, ISO 27001 clauses, and price assertions. All column values are drawn from the domain of information-security product documentation and audit records.

## 1. Schema Overview and Domain Grounding

The five tables implement the slot structures of the supplied axioms without alteration. Primary keys are opaque identifiers; foreign keys enforce the existential restrictions expressed by the Manchester axioms. The domain consists of entries for organizations holding tax identifiers, descriptive claims about control effectiveness, ISO 27001 clause references, minimal attribute sets, and product price statements.

## 2. Cross-Join Example

To determine the ISO 27001 clause and product price associated with the organization whose tax identifier is linked to claim-001, perform the following joins:

```sql
SELECT
  t1.x AS organization,
  t3.x AS clause,
  t5.x AS priced_artifact
FROM t_schemaorg_org_taxid t1
JOIN t_outlier_claim_min_one_attribute t2 ON t1.y = t2.id
JOIN t_iso27001_clause_subclass t3 ON t2.id = t3.y
JOIN t_schemaorg_product_price t5 ON t2.id = t5.y
WHERE t1.id = 'org-tax-01';
```

The result row is:

organization: Veoneer-Vision-Unit  
clause: A.12.4.1  
priced_artifact: Veoneer-Vision-Module

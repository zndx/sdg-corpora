# System Call Classification in eBPF Tracing Subsystems

This chapter defines a minimal relational schema that materializes five OWL axioms for system calls treated as designative information content entities. The schema supports multi-hop queries over subsystem membership, return-type cardinality, traceability, and security tier by means of primary-key and value-based foreign-key references.

## 1 Schema Overview

Five tables directly encode the supplied axioms. Each table contains an opaque surrogate identifier as primary key. Columns named x hold references to syscall classes; columns named y hold references to subsystem, return-type, tracer, or tier classes. Joins are performed by equating x or y values across tables, permitting reconstruction of compound classifications such as “a traceable syscall at a given security tier whose return type is recorded in exactly one table.”

### 1.1 t_syscall_basic

This table embodies axiom 5 by recording every class that is a direct subclass of cco:DesignativeICE. Column id is the primary key; column x is the syscall class name and carries no foreign-key constraint.

```sql
CREATE TABLE t_syscall_basic (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

Example rows:

| id       | x          |
|----------|------------|
| sb-001   | read       |
| sb-002   | write      |
| sb-003   | openat     |
| sb-004   | close      |
| sb-005   | mmap       |
| sb-006   | socket     |

### 1.2 t_syscall_equiv_in_subsystem

This table embodies axiom 1 by asserting equivalence of a syscall class to a designative ICE located inside a named syscall subsystem. Column id is the primary key; column x references a row in t_syscall_basic via value equality; column y identifies the subsystem class and is required.

```sql
CREATE TABLE t_syscall_equiv_in_subsystem (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

Example rows:

| id       | x        | y                |
|----------|----------|------------------|
| se-001   | read     | file_subsystem   |
| se-002   | write    | file_subsystem   |
| se-003   | openat   | file_subsystem   |
| se-004   | close    | file_subsystem   |
| se-005   | mmap     | memory_subsystem |
| se-006   | socket   | net_subsystem    |

### 1.3 t_syscall_max_one_return

This table embodies axiom 2 by restricting each syscall class to at most one return type. Column id is the primary key; column x references t_syscall_basic; column y is an optional return-type class.

```sql
CREATE TABLE t_syscall_max_one_return (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255),
  PRIMARY KEY (id)
);
```

Example rows:

| id       | x        | y     |
|----------|----------|-------|
| sr-001   | read     | ssize |
| sr-002   | write    | ssize |
| sr-003   | openat   | int   |
| sr-004   | close    | int   |
| sr-005   | mmap     | void* |
| sr-006   | socket   | int   |

### 1.4 t_syscall_traceable

This table embodies axiom 3 by linking each syscall class to one or more tracing mechanisms. Column id is the primary key; column x references t_syscall_basic; column y identifies the tracer class and is required.

```sql
CREATE TABLE t_syscall_traceable (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

Example rows:

| id       | x        | y          |
|----------|----------|------------|
| st-001   | read     | kprobe     |
| st-002   | read     | tracepoint |
| st-003   | write    | kprobe     |
| st-004   | openat   | tracepoint |
| st-005   | mmap     | kprobe     |
| st-006   | socket   | tracepoint |

### 1.5 t_syscall_at_security_tier

This table embodies axiom 4 by assigning each syscall class to a security tier. Column id is the primary key; column x references t_syscall_basic; column y identifies the tier class and is required.

```sql
CREATE TABLE t_syscall_at_security_tier (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

Example rows:

| id       | x        | y          |
|----------|----------|------------|
| ss-001   | read     | tier_2     |
| ss-002   | write    | tier_2     |
| ss-003   | openat   | tier_3     |
| ss-004   | close    | tier_1     |
| ss-005   | mmap     | tier_3     |
| ss-006   | socket   | tier_4     |

## 2 Cross-Join Example

To retrieve every file-subsystem syscall that is traceable by kprobe and assigned to tier_2, evaluate the following mental join path. Start with t_syscall_equiv_in_subsystem where y = 'file_subsystem', match x against t_syscall_traceable where y = 'kprobe', then match the same x against t_syscall_at_security_tier where y = 'tier_2'. The single row satisfying all three conditions is:

read (sb-001)  
  subsystem file_subsystem (se-001)  
  traceable kprobe (st-001)  
  tier  tier_2 (ss-001)  
  return ssize (sr-001)

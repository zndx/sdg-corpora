# Regulatory Directive Modeling: Publication Dates, Specifications, and Event Temporal Anchors

This chapter presents four tables that encode the projection of four OWL axioms into a relational schema. The tables capture directives that specify targets, publication dates of artifacts, and start and end times of events. All column values are instances consistent with the slot types of the source axioms. Primary-key and foreign-key relationships enable cross-table queries that recover multi-hop facts such as the publication date of a directive that applies to a given target and the start and end times attached to that directive.

## 1. Core Tables and Axiom Embodiment

### 1.1 t_requirement_equiv_specifies_target
This table embodies AXIOM 2. Column id is the primary key. Column y is a foreign key referencing t_schemaorg_creativework_date(id) and records the publication date of the directive; column z records the target to which the directive applies. A reader can join on y to retrieve the publication date for any directive and then follow z to identify the regulated target.

```sql
CREATE TABLE t_requirement_equiv_specifies_target (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  z VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_schemaorg_creativework_date(id)
);
```

### 1.2 t_schemaorg_creativework_date
This table embodies AXIOM 1. Column id is the primary key. Column y is a foreign key referencing t_requirement_equiv_specifies_target(id) and records the directive whose publication date is asserted. A reader can join on y to obtain the directive identifier for any given publication date.

```sql
CREATE TABLE t_schemaorg_creativework_date (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_requirement_equiv_specifies_target(id)
);
```

### 1.3 t_schemaorg_event_starttime
This table embodies AXIOM 3. Column id is the primary key. Column y is a foreign key referencing t_requirement_equiv_specifies_target(id) and records the directive that governs the event start time. A reader can join on y to retrieve the directive and its publication date for any start-time assertion.

```sql
CREATE TABLE t_schemaorg_event_starttime (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_requirement_equiv_specifies_target(id)
);
```

## 2. Cross-Join Demonstration

To recover the publication date together with start and end times for the directive that applies to “Target:PreK-K_Orientation”, execute the following mental join sequence:

1. Locate req-01 in t_requirement_equiv_specifies_target (z = Target:PreK-K_Orientation).
2. Follow y = cd-01 into t_schemaorg_creativework_date to obtain x = 2017-08-14.
3. Follow req-01 into t_schemaorg_event_starttime (y) to obtain x = 18:30.
4. Follow req-01 into t_schemaorg_event_endtime (y) to obtain x = 19:30.

Resulting joined row: (directive = req-01, publication_date = 2017-08-14, start_time = 18:30, end_time = 19:30, target = Target:PreK-K_Orientation).

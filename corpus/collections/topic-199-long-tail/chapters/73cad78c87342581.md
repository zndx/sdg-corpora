# Commission Directive Scheduling and Event Timing

This chapter defines a minimal relational schema for representing municipal commission directives and their associated publication dates and event timings. The schema directly implements four ontological axioms that capture artifactual works, directive equivalence classes, and temporal extents. All tables share a uniform identifier space so that primary-key and foreign-key values serve as join paths for multi-hop retrieval.

## 1. Requirement Equivalence and Specification

Axiom 2 states that a class X is equivalent to a DirectiveICE that specifies some target Y and applies to some target Z. The table below materializes this axiom. Column id is the primary key. Column y is a foreign key into t_schemaorg_creativework_date, and column z is a foreign key into the same table, allowing a directive to be resolved against both its specification and its applicability scope.

```sql
CREATE TABLE t_requirement_equiv_specifies_target (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  z VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_schemaorg_creativework_date(id)
);
```

## 2. Creative Work Publication Date

Axiom 1 states that an artifact X has a date published Y. The table below implements this axiom. Column id is the primary key. Column y is a foreign key into t_requirement_equiv_specifies_target, linking each publication date to the directive that governs its release.

```sql
CREATE TABLE t_schemaorg_creativework_date (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_requirement_equiv_specifies_target(id)
);
```

## 3. Event Start Time

Axiom 3 states that an artifact X has an event start time Y. The table below implements this axiom. Column id is the primary key. Column y is a foreign key into t_requirement_equiv_specifies_target, allowing a start time to be traced to the directive that mandates the event window.

```sql
CREATE TABLE t_schemaorg_event_starttime (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_requirement_equiv_specifies_target(id)
);
```

## 4. Event End Time

Axiom 4 states that an artifact X has an event end time Y. The table below implements this axiom. Column id is the primary key. Column y is a foreign key into t_requirement_equiv_specifies_target, completing the temporal bounds of each directive-governed event.

```sql
CREATE TABLE t_schemaorg_event_endtime (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_requirement_equiv_specifies_target(id)
);
```

## 5. Cross-Join Example

To retrieve the start time, end time, and governing directive for the Back-to-School event, join t_schemaorg_event_starttime to t_requirement_equiv_specifies_target on y = id, then join t_schemaorg_event_endtime on the same requirement identifier:

- start-02 (18:00) → req-03 → end-02 (19:30)

# Chapter 4: Governance of Academic Artifacts and Temporal Directives

## 4.1 Scope and Preamble

This chapter delineates the structural governance required for managing academic artifacts, specifically focusing on the intersection of creative works, regulatory directives, and temporal constraints. It establishes the necessary compliance frameworks for ensuring that institutional schedules—ranging from school calendars to doctoral thesis submissions—adhere to strict ontological definitions. The following sections provide a detailed breakdown of the relational mappings between artifacts, their publication dates, and the governing directives that specify their operational parameters.

## 4.2 Artifact Publication Dating

In the context of academic governance, the publication of a creative work is not merely a dissemination of information but a compliance event anchored to a specific temporal entity. The axiom `schemaorg_creativework_date` posits that any artifact classified as a `cco:Artifact` must possess a `sdg:hasDatePublished` property. This relationship ensures that every calendar, bulletin, or thesis synopsis is traceable to a definitive publication moment, establishing the baseline for its validity and audit trail.

The relationship between the artifact and the date is governed by a foreign key constraint that links the date entity to a specific requirement directive. This implies that a date is not published in a vacuum; rather, it is published as a fulfillment of a directive. For instance, the "Basic School Calendar for 2017-2018" (Style Reference 1) is an artifact whose publication date is inextricably linked to the administrative directive requiring its release.

## 4.3 Directive Equivalence and Target Specification

The core of the governance framework lies in the definition of requirements through the axiom `requirement_equiv_specifies_target`. This axiom asserts that a class `X` is equivalent to the intersection of a `cco:DirectiveICE`, a specification of a target `Y`, and an application to a context `Z`. In practical terms, this means that a governance directive is only valid when it explicitly specifies a target (the date or event) and applies to a specific scope (such as a student body or academic department).

This equivalence class creates a rigid structure for compliance auditing. A directive cannot exist independently; it must be tied to a target entity (which, as per the schema, is the publication date ID) and a scope entity. This circular dependency between the requirement and the date ensures that no temporal artifact exists without a governing directive, and no directive exists without a target.

## 4.4 Event Start Time Governance

To enforce temporal discipline, the framework utilizes the axiom `schemaorg_event_starttime`. This axiom defines that an artifact (specifically an event) must have a `sdg:hasEventStartTime` property. In the relational schema, this start time is not a simple timestamp string but a reference to the governing directive ID. This design choice reinforces the principle that time is a governed resource; an event starts when the directive permits it to start.

For example, the "Orientation/Ice Cream Social" listed in Style Reference 1 does not simply begin at 6:30 P.M.; it begins because the directive `req_dir_01` defines that start time. By linking the start time to the directive, the system ensures that any change in the schedule must propagate through the governance layer, maintaining the integrity of the audit trail.

## 4.5 Event End Time Governance

Complementing the start time governance, the axiom `schemaorg_event_endtime` mandates that every event artifact must have an `sdg:hasEventEndTime`. Consistent with the start time logic, this end time is modeled as a reference to the directive ID. This creates a symmetrical structure where the duration of an event is bounded by the same directive that governs its publication and context.

This structure is critical for resource allocation and conflict detection. By querying the directive IDs associated with end times, administrators can ensure that events such as the "Back to School Kick-Off" (Style Reference 1) or the "Teacher-led clubs" (Style Reference 3) do not overlap or overrun their allocated slots. The strict foreign key relationship ensures that an end time cannot be defined without a valid governing directive.

This holistic view of the data—spanning publication dates, directive targets, and start/end times—provides a robust, evidence-anchored framework for academic governance.

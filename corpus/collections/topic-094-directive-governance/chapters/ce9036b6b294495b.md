# Chapter 4: Modeling Directive Verification and Claim Support in Regulatory Audit Trails

This chapter defines five relational tables that instantiate the ontology axioms trace_supports_claim, requirement_min_one_verification, kernel_anomaly_supports_claim, column_lineage_for_compliance_claim, and dataset_under_audit. The tables record how directive information content entities are verified, how artifacts support descriptive claims, and how datasets participate in audit processes. All rows are drawn from instances that appear in securities filings, corporate meeting records, and board agendas.

## 1 Table Definitions and Axiom Mappings

### 1.1 t_trace_supports_claim
This table embodies axiom 1 (trace_supports_claim). Column id is the primary key; column x holds the class that supports a descriptive information content entity. A reader can join this table to t_requirement_min_one_verification on id = y to retrieve the directive that each trace verifies.

| id | x |
| id | x |
| trace_001 | Form_10Q_Section13 |
| trace_002 | Attendance_Slip_Court_Meeting |
| trace_003 | Board_Agenda_Payroll_Study |
| trace_004 | Commission_File_Number |
| trace_005 | Quarterly_Period_Ended |

### 1.2 t_requirement_min_one_verification
This table embodies axiom 2 (requirement_min_one_verification). Column id is the primary key; column x holds the directive information content entity; column y is a foreign key referencing t_trace_supports_claim.id. A reader can join on y to obtain at least one supporting trace for each directive.

| id | x | y |
| id | x | y |
| req_001 | Directive_10Q_Filing | trace_001 |
| req_002 | Directive_Attendance_Verification | trace_002 |
| req_003 | Directive_Agenda_Approval | trace_003 |

| req_005 | Directive_Period_Reporting | trace_005 |
| req_006 | Directive_Transition_Report | trace_001 |

This table embodies axiom 5 (dataset_under_audit). Column id is the primary key; column x holds the artifact class that participates in an audit process. No foreign key is defined; rows identify datasets subject to process scrutiny.

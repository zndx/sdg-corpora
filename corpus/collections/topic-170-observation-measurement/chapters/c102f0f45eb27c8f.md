# Modeling Artifact Locations and Organizational Identifiers

This chapter presents five relational tables that encode schema.org-derived properties for artifacts. The tables support retrieval of postal addresses, geographic coordinates, latitude values, longitude values, and tax identifiers through joins on shared class references.

## 1. Schemaorg Place Address Table

Axiom 1 states that an artifact class instance bears a postal address class instance. The table uses id as primary key; x references an artifact and y references its address, enabling direct lookup of address data for any artifact.

```sql
CREATE TABLE t_schemaorg_place_address (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

# Ontological Modeling of Claim Attestation in Periodical Archives

This chapter specifies four table structures that realize axioms for descriptive information content entities, processes bearing supporting evidence, and refutation or non-disconfirmation relations. The structures support cross-table joins that trace a claim through its frame of discernment, evidentiary process, and confirmation status within archival records drawn from periodical and administrative sources.

## 1 Table t_mass_function_subclass

This table embodies axiom 1 by recording each mass function as a subclass of DescriptiveICE whose frame of discernment is supplied by an attestation process. Column id is the primary key; column y is a foreign key referencing t_attestation_with_supporting_evidence.id, enabling a join that retrieves the supporting process for any given frame.

| id | x | y |
| mfs_001 | ReasoningPath | att_003 |
| mfs_002 | BhaktiPath | att_001 |
| mfs_003 | CheerfulState | att_004 |
| mfs_004 | DivineWisdom | att_002 |
| mfs_005 | EstrogenZoneEvent | att_005 |

## 2 Table t_attestation_with_supporting_evidence

This table embodies axiom 2 by recording each attestation as a subclass of bfo:Process that carries a supporting mass function. Column id is the primary key; column y is a foreign key referencing t_mass_function_subclass.id, closing the bidirectional link required by the paired axioms.

| id | x | y |
| id | x | y |
| att_001 | MasterDiscourse | mfs_001 |
| att_002 | SwamiStatement | mfs_003 |
| att_003 | CalendarEntry | mfs_004 |
| att_004 | PermitNarrative | mfs_002 |
| att_005 | BoardMinutes | mfs_005 |

## 3 Table t_claim_refuted_by_evidence

This table embodies axiom 3 by recording each refuted claim as a subclass of DescriptiveICE whose refuting evidence is an attestation. Column id is the primary key; column y is a foreign key referencing t_attestation_with_supporting_evidence.id, permitting a join that isolates claims whose supporting processes have been contradicted.

| id | x | y |
| id | x | y |
| cre_001 | NewAtheismAssertion | att_001 |
| cre_002 | UnlimitedKnowledgeClaim | att_003 |
| cre_003 | MarketingOmission | att_005 |
| cre_004 | SpecialExceptionDenial | att_002 |

## 4 Table t_claim_not_disconfirmed

This table embodies axiom 4 by recording each claim that remains outside a given class. Column id is the primary key; no foreign-key column is present, so rows are joined only through shared literal values in x or y.

| id | x | y |
| id | x | y |
| cnd_001 | BhaktiPath | DisconfirmedPath |
| cnd_002 | DivineWisdom | DisconfirmedState |
| cnd_003 | CheerfulState | DisconfirmedEvent |
| cnd_004 | ReasoningPath | DisconfirmedDiscourse |

## 5 Multi-hop query example

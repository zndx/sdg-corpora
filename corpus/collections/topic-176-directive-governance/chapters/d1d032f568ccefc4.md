# Chapter 7: Directive Governance Processes — Verification, Audit, and Attestation

This chapter presents four ontological templates that classify processes under BFO:0000015 within the directive-governance family. Each template is realized as a single relational table whose columns directly encode the Manchester axioms. The resulting schema supports multi-table joins that recover evidence chains and signer constraints without additional mapping layers.

## 1 Ontology-to-Relation Mapping

The four axioms project to four tables. Primary keys are synthetic identifiers of the form “VME-###”, “VB-###”, “AB-###”, and “AM-###”. Foreign-key columns appear only where an axiom introduces a qualified cardinality restriction; they reference primary keys of peer tables that instantiate the required filler class.

### 1.1 t_verification_min_one_evidence

This table embodies the axiom “Class: {X:Class} SubClassOf: bfo:0000015, sdg:producesEvidence min 1 {Y:Class}”. Column id is the primary key. Column x stores the verification process identifier. Column y is a non-null foreign key that must resolve to the primary key of any row in t_audit_basic or t_attestation_min_one_signer, thereby satisfying the evidence requirement.

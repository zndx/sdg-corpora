# Laboratory Event Modeling Using OWL-Derived Schemas

This chapter defines a minimal relational schema for laboratory events. Three tables encode the axioms observation_with_participant, artifact_min_one_owner, and schemaorg_place_address. Primary and foreign keys permit two- and three-table joins that recover multi-hop facts such as the postal address linked to the owner of a given artifact.

## 1 Observation with Participant

Table t_observation_with_participant embodies axiom 2. Column id is the primary key. Column x names the process class. No foreign keys exist; the table therefore serves as the join target for the remaining two tables. A reader can locate every artifact owner and every postal address by joining on this id.

| id     | x                    |
|--------|----------------------|
| obs001 | EquipmentCalibration |
| obs002 | SampleReceipt        |
| obs003 | TemperatureLog       |
| obs004 | MaintenanceCheck     |
| obs005 | ChainOfCustody       |

## 1.1 Artifact with Minimum One Owner

Table t_artifact_min_one_owner embodies axiom 3. Column id is the primary key. Column x names the artifact class. Column y is a foreign key referencing t_observation_with_participant(id) and records the required owner observation. Joining on y yields the process that owns each artifact.

| id      | x               | y      |
|---------|-----------------|--------|
| art001  | CentrifugeX7    | obs001 |
| art002  | FreezerA4       | obs004 |
| art003  | BalanceK3       | obs001 |
| art004  | PipetteSetB     | obs002 |
| art005  | IncubatorM2     | obs003 |
| art006  | MicroscopeZ1    | obs005 |

## 1.2 Place with Postal Address

Table t_schemaorg_place_address embodies axiom 1. Column id is the primary key. Column x names the place class. Column y is a foreign key referencing t_observation_with_participant(id) and records the observation that supplies the address. Joining on y recovers the address observation for any place.

| id     | x             | y      |
|--------|---------------|--------|
| plc001 | NorthLab      | obs002 |
| plc002 | EastStorage   | obs003 |
| plc003 | WestPrep      | obs001 |
| plc004 | SouthArchive  | obs005 |
| plc005 | CentralCore   | obs004 |

## 2 Cross-Join Example

Question: which postal address is recorded for the observation that owns artifact CentrifugeX7?

Step 1. Locate the artifact row (art001) and read foreign key y = obs001.  
Step 2. Locate the address row whose y equals obs001; read x = WestPrep.

Result row after the two joins:

| artifact_id | artifact_x   | owner_obs | place_x   |
|-------------|--------------|-----------|-----------|
| art001      | CentrifugeX7 | obs001    | WestPrep  |

The same pattern extends to three tables when an additional owner or address observation is required.

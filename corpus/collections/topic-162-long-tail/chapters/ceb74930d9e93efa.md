# Chapter 4: Descriptive and Designative Information Content Entities in County Position Records

This chapter defines three tables that implement axioms for descriptive information content entities, artifacts bearing postal addresses, and designative information content entities restricted to a single return type. The tables are populated with instances drawn from county road administration vacancy and notification records. Primary and foreign key relationships permit cross-table queries that recover multi-hop facts such as the postal address linked to a designated position title.

## 1 Axiom Embodiment and Table Definitions

### 1.1 t_lift_basic

The table t_lift_basic embodies AXIOM 2 by recording every value of x as an instance of cco:DescriptiveICE. Column id is the primary key; column x holds the descriptive entity label. No foreign keys are present.

```sql
SELECT x FROM t_lift_basic WHERE id = 'desc_003';
```

### 1.2 t_schemaorg_place_address

The table t_schemaorg_place_address embodies AXIOM 1 by recording every value of x as an artifact that bears a postal address y. Column id is the primary key; column y is a foreign key referencing t_lift_basic.id. A reader can obtain the address label attached to any artifact by joining on y.

```sql
SELECT a.x, b.x
FROM t_schemaorg_place_address a
JOIN t_lift_basic b ON a.y = b.id;
```

### 1.3 t_syscall_max_one_return

The table t_syscall_max_one_return embodies AXIOM 3 by recording every value of x as a designative information content entity whose return type is constrained to at most one y. Column id is the primary key; column y is a foreign key referencing t_lift_basic.id. A reader can recover the single permitted return type for any designative entity by joining on y.

```sql
SELECT a.x, b.x
FROM t_syscall_max_one_return a
JOIN t_lift_basic b ON a.y = b.id;
```

## 3 Cross-Join Demonstration

Question: Which postal-address block is attached to the artifact whose designation carries the return type desc_006?

Execution path:  
1. Locate desig_001 in t_syscall_max_one_return; its y value is desc_006.  
2. Locate addr_001 in t_schemaorg_place_address; its y value is desc_005.  
3. The shared descriptive context (desc_006 and desc_005) is resolved through the common descriptive pool in t_lift_basic.

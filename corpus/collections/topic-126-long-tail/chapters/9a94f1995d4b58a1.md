# Artifact Attribute Modeling for Products and Places

This chapter defines four relations that capture brand, price, postal address, and longitude attributes of artifacts. The relations are expressed as relational tables whose rows are instances of the supplied OWL axioms. Primary keys ensure uniqueness of each attribution statement; shared values in the x column permit equi-joins that recover all attributes of a single artifact.

## 1. Product–Brand Attribution

The table t_schemaorg_product_brand embodies axiom schemaorg_product_brand. Column id is the primary key; columns x and y are entity references with no foreign-key constraint declared in the schema. Joining on x with any other table that also references the same artifact yields the brand together with additional attributes.

```sql
CREATE TABLE t_schemaorg_product_brand (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

## 1.1 Product–Price Attribution

The table t_schemaorg_product_price embodies axiom schemaorg_product_price. Column id is the primary key. An equi-join on x with t_schemaorg_product_brand recovers both brand and price for any artifact that carries both attributions.

```sql
CREATE TABLE t_schemaorg_product_price (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

## 2. Place–Address Attribution

The table t_schemaorg_place_address embodies axiom schemaorg_place_address. Column id is the primary key. Because place artifacts may also appear in the longitude table, an equi-join on x assembles the complete postal record.

```sql
CREATE TABLE t_schemaorg_place_address (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

## 2.1 Place–Longitude Attribution

The table t_schemaorg_place_longitude embodies axiom schemaorg_place_longitude. Column id is the primary key. Joining on x with t_schemaorg_place_address supplies both address and longitude for the same place artifact.

```sql
CREATE TABLE t_schemaorg_place_longitude (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

## 3. Cross-Table Retrieval Example

To obtain the price and brand of every artifact supplied from a place whose longitude lies west of −71.3, first join t_schemaorg_product_brand and t_schemaorg_product_price on x, then restrict the resulting artifacts to those whose supplier place satisfies the longitude predicate obtained from a second join between t_schemaorg_place_address and t_schemaorg_place_longitude. The equi-join on x across the four tables yields:

- ZoomKit-47, TechBrand, 149.00, MainOffice, −71.3492
- TeleMic-03, TechBrand, 89.00, MainOffice, −71.3492
- CableSet-21, TechBrand, 17.25, TeleMedia2, −71.3501

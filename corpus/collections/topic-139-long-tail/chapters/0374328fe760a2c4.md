# Ontological Modeling of Laboratory Processes via Relational Schemas

This chapter defines five tables that instantiate OWL axioms for processes emitting metrics, following protocols, and supporting syscall traceability. The schema supports cross-table joins that resolve multi-hop queries over laboratory runs, alerts, and kernel-level observations.

## 1 Scope and Schema Overview

The tables embody five template axioms that specialize bfo:0000015 (process) and cco:DesignativeICE. Primary keys are the id columns; foreign keys enforce the slot restrictions declared in each axiom. Four tables contain between four and six rows; one table contains four rows. All foreign-key values reference existing primary-key values.

### 1.1 t_metric_emission_subclass

This table realizes axiom 1 (metric_emission_subclass). Column id is the primary key; column y is a foreign key to t_labrun_with_protocol.id and records the metric class emitted by the process class in column x.

| id  | x                    | y    |
|-----|----------------------|------|
| mes1| SampleAnalysis       | lrp1 |
| mes2| EquipmentCalibration | lrp2 |
| mes3| ReagentPreparation   | lrp3 |
| mes4| DataArchival         | lrp4 |
| mes5| ContaminationCheck   | lrp1 |

### 1.2 t_labrun_with_protocol

This table realizes axiom 2 (labrun_with_protocol). Column id is the primary key; column y is a foreign key to t_metric_emission_subclass.id and records the protocol class followed by the process class in column x.

| id  | x                 | y    |
|-----|-------------------|------|
| lrp1| SampleAnalysis    | mes1 |
| lrp2| EquipmentCalibration | mes2 |
| lrp3| ReagentPreparation | mes3 |
| lrp4| DataArchival      | mes4 |
| lrp5| ContaminationCheck | mes5 |

### 1.3 t_syscall_traceable

This table realizes axiom 3 (syscall_traceable). Column id is the primary key; column y is a foreign key to t_labrun_with_protocol.id and records the designative ICE that traces the class in column x.

| id  | x                    | y    |
|-----|----------------------|------|
| st1 | SampleAnalysis       | lrp1 |
| st2 | EquipmentCalibration | lrp2 |
| st3 | ReagentPreparation   | lrp3 |
| st4 | DataArchival         | lrp4 |

### 1.4 t_alert_triggered_by

This table realizes axiom 4 (alert_triggered_by). Column id is the primary key; column y is a foreign key to t_labrun_with_protocol.id and records the metric class that triggers the alert class in column x.

| id  | x               | y    |
|-----|-----------------|------|
| at1 | ThresholdAlert  | lrp1 |
| at2 | DriftAlert      | lrp2 |
| at3 | ProtocolAlert   | lrp3 |

### 1.5 t_ebpfevent_observes_syscall_xref

This table realizes axiom 5 (ebpfevent_observes_syscall_xref). Column id is the primary key; column x records the process class that observes a syscall designative ICE.

| id  | x                    |
|-----|----------------------|
| eb1 | SampleAnalysis       |
| eb2 | EquipmentCalibration |
| eb3 | ReagentPreparation   |
| eb4 | DataArchival         |

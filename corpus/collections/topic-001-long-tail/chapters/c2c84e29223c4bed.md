# Chapter 4: Directive Governance Processes in Commission Audit Trails

This chapter presents five relational tables that realize OWL axioms for processes under the bfo:0000015 hierarchy. The tables capture verification, attestation, and audit activities within the Ashland Water and Sewer Commission record-keeping system. Primary keys identify individual process instances; foreign-key columns carry entity references that support two- and three-table joins.

## 1. Verification with Evidence Requirement

Axiom 1 states that a verification process must produce at least one evidence item. Table t_verification_min_one_evidence implements the axiom by storing the process class in column x and the required evidence class in column y. Column id is the primary key. Column y functions as a foreign key that resolves to an instance of evidence maintained in an external registry.

```sql
CREATE TABLE t_verification_min_one_evidence (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

Example rows:

| id | x | y |
| --- | --- | --- |
| vrf-2016-001 | MinutesVerification | AttendanceRecord |
| vrf-2016-002 | MinutesVerification | MotionLog |
| vrf-2019-003 | SubmissionVerification | ReviewerReport |
| vrf-2019-004 | SubmissionVerification | ConflictDeclaration |

## 1.1 Verification Process Registry

Axiom 2 defines an unqualified verification process. Table t_verification_basic records each such process under column x. Column id is the primary key and may be referenced by y values in t_verification_min_one_evidence.

## 2. Attestation with Required Signer

Axiom 3 requires that an attestation process be signed by at least one person. Table t_attestation_min_one_signer stores the process class in column x. Column id is the primary key. The signer constraint is satisfied by an external link to cco:Person not materialized in this table.

```sql
CREATE TABLE t_attestation_min_one_signer (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

Example rows:

| id | x |

## 5. Cross-Table Query Example

Start with t_verification_min_one_evidence row vrf-2016-001 (x = MinutesVerification, y = AttendanceRecord). Match x to t_verification_basic row vrf-2016-001.

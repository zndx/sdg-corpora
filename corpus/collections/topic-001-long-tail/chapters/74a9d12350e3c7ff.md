# Directive Governance in Municipal Record Processes

This chapter presents five relational tables that implement OWL axioms for bfo:Process subclasses in the directive_governance family. The tables capture verification, attestation, and audit processes drawn from commission meeting records. Primary keys identify each process instance; foreign-key references enable multi-hop queries across evidence production and signer requirements.

## 1. Table Structures and Axiom Embodiment

## 2. Cross-Join Demonstration

A multi-hop query retrieves the evidence produced by a verification process that is also attested by a signer. Join t_verification_min_one_evidence on x to t_verification_basic, then link the resulting process to t_attestation_min_one_signer via shared x values.

Example: start at verif_ev_01 (x = MinutesReviewAugust2016, y = EvidencePacket001). The x value matches verif_b_01 and also matches attest_sign_01. The joined row yields process MinutesReviewAugust2016, evidence EvidencePacket001, and attestation MinutesApprovalAugust2016.

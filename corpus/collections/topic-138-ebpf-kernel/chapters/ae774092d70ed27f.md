# GDPR Directive Governance: Ontological Axioms Realized as Relational Schema

This chapter maps five OWL axioms for directive governance processes to a fixed relational schema. The schema supports cross-table queries that resolve multi-hop relationships among controls, lawful bases, attestations, verifications, and article subclasses. All column values are instances consistent with the slot types declared in the axioms.

## 1 Schema Overview

The five tables embody the axioms listed in Section 2. Primary keys are the `id` columns. Foreign-key columns implement the `some` restrictions, enabling joins that traverse from a control to its required evidence, from a verification to its produced evidence, and from an attestation to its supporting lawful basis.

### 1.1 t_control_with_evidence_requirement

Axiom 5 is realized by this table. Column `id` is the primary key. Column `y` is a foreign key to `t_gdpr_lawful_basis(id)`, recording the evidence required by each directive instance. A reader can join on `y` to retrieve the lawful-basis identifier that satisfies a given control’s evidence requirement.

| id | x | y |
| id | x | y |
| ctrl-01 | ConsentCapture | lb-06-1a |
| ctrl-02 | DataMinimizationCheck | lb-06-1c |
| ctrl-03 | RetentionPolicyEnforcement | lb-06-1b |
| ctrl-04 | AccessRequestHandling | lb-06-1a |
| ctrl-05 | BreachNotificationTrigger | lb-06-1f |

### 1.2 t_gdpr_lawful_basis

Axiom 2 is realized by this table. Column `id` is the primary key. Column `y` is a foreign key to `t_control_with_evidence_requirement(id)`, recording the control that supplies the lawful basis. A reader can join on `y` to obtain the control identifier that grounds each lawful-basis claim.

### 1.3 t_gdpr_article_subclass

Axiom 4 is realized by this table. Column `id` is the primary key. Column `y` is a foreign key to `t_control_with_evidence_requirement(id)`, recording the control that implements the cited GDPR article. A reader can join on `y` to list all article subclasses that a single control satisfies.

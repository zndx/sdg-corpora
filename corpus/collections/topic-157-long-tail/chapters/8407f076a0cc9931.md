# Kernel Event Threading and Mass Function Equivalence in Descriptive Frames

This chapter defines two core ontological patterns for representing kernel-level processes that carry thread identifiers and for encoding mass function equivalences over frames of discernment. The patterns are realized as a minimal relational schema whose foreign-key links permit multi-hop retrieval of thread-to-assignment provenance.

## 1. Axiom Embodiment and Table Structure

### 1.1 Kernel Event with Thread Identifier

Axiom 1 states that any instance of class X is a bfo:Process that is linked to a thread identifier Y. The corresponding table records each such event once; its primary key is the event identifier, while the y column is a foreign key that resolves to a mass-function equivalence record. A reader can therefore retrieve, for any kernel event, the frame and assignment that supplied its thread identifier by joining on y.

| id | x | y |
|----|---|----|
| ke-001 | KernelThreadCreate | mf-010 |
| ke-002 | KernelThreadExit | mf-011 |
| ke-003 | KernelThreadCreate | mf-012 |
| ke-004 | KernelThreadSchedule | mf-010 |
| ke-005 | KernelThreadBlock | mf-013 |

### 1.2 Mass Function Equivalence Frame and Assignment

Axiom 2 declares that class X is equivalent to a cco:DescriptiveICE that simultaneously ranges over a frame of discernment Y and assigns mass to a focal element Z. The table stores one equivalence per row; its primary key is the equivalence identifier, while the y column is a foreign key back to a kernel-event record. The circular foreign-key pair between the two tables therefore encodes mutual grounding: an event supplies the thread context for an equivalence, and the equivalence supplies the frame that justifies the thread identifier.

| id | x | y | z |
|----|---|----|----|
| mf-010 | ThreadMassEquiv | ke-001 | FrameThreadPool |
| mf-011 | ThreadMassEquiv | ke-002 | FrameThreadPool |
| mf-012 | ThreadMassEquiv | ke-003 | FrameScheduler |
| mf-013 | ThreadMassEquiv | ke-005 | FrameBlockQueue |
| mf-014 | ThreadMassEquiv | ke-004 | FrameThreadPool |

## 2. Cross-Join Demonstration

To recover the frame of discernment and focal element that justify the thread identifier carried by kernel event ke-004, first locate the row in t_kernel_event_with_tid where id = 'ke-004'. Its y value is 'mf-010'. The matching row in t_mass_function_equiv_frame_and_assignment supplies x = 'ThreadMassEquiv', y = 'ke-001' (the reciprocal event link), and z = 'FrameThreadPool'.

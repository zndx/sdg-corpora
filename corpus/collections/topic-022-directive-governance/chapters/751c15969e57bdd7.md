# Compliance Ontology for Artifact Branding and ISO 27001 Directive Classification

This chapter defines the relational projection of three OWL axioms that capture brand attribution on artifacts and hierarchical placement of directives under ISO 27001 Annex A and clauses. The resulting schema consists of three tables whose rows are populated with concrete class references drawn from security-product and control documentation. Primary keys are synthetic identifiers; cross-table navigation occurs by value equality on the shared class columns x and y.

## 1 Schema Structure and Axiom Embodiment

### 1.1 t_schemaorg_product_brand
This table embodies AXIOM 1 by recording pairs in which an artifact class (x) is asserted to carry a brand class (y). Column id is the primary key; no foreign-key columns exist inside the table, but values in y may be joined to x columns of the ISO 27001 tables when the same class identifier appears.

| id | x | y |
| id | x | y |
| pb-001 | SecureGateway | Veoneer |
| pb-002 | AccessController | bp |
| pb-003 | AuditLogger | Veoneer |
| pb-004 | EncryptionModule | AcmeSec |
| pb-005 | PolicyServer | bp |

### 1.2 t_iso27001_annexa_subclass
This table embodies AXIOM 2 by recording pairs in which a directive class (x) is placed under an Annex A category (y). Column id is the primary key; y values serve as join points to x values in the clause table when control families are further decomposed.

| id | x | y |
| id | x | y |
| ia-010 | InformationSecurityPolicy | A.5 |
| ia-011 | AccessControlPolicy | A.9 |
| ia-012 | LoggingAndMonitoring | A.12 |
| ia-013 | SupplierSecurity | A.15 |
| ia-014 | IncidentManagement | A.16 |
| ia-015 | EncryptionControls | A.10 |

### 1.3 t_iso27001_clause_subclass
This table embodies AXIOM 3 by recording pairs in which a directive class (x) is placed under a numbered clause (y). Column id is the primary key; x values may be joined to y values in the Annex A table or to y values in the brand table when a directive also functions as a branded artifact.

## 2 Multi-hop Query Example

Question: Which brand is carried by the artifact that realizes the directive placed under both Annex A category A.12 and clause 12.4?

Walk the links as follows.  
Row ia-012 in t_iso27001_annexa_subclass supplies x = LoggingAndMonitoring for y = A.12.  
Row ic-022 in t_iso27001_clause_subclass supplies the same x = LoggingAndMonitoring for y = 12.4.  
Row ic-026 supplies x = AuditLogger for y = 12.4.  
Row pb-003 in t_schemaorg_product_brand supplies x = AuditLogger for y = Veoneer.

Joined result row: (AuditLogger, Veoneer, A.12, 12.4).

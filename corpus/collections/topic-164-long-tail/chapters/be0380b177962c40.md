# Ontological Modeling of Laboratory Processes Using Relational Schemas

This chapter presents four axioms that constrain processes and measurements within laboratory information management. The axioms are materialised as four tables whose primary and foreign keys enforce the required cardinalities and equivalences. Cross-table joins recover multi-hop facts such as the dimension and unit of an output produced by a process that accepts a given input.

## 1 Table Structures and Axiom Correspondence

### 1.1 t_measurement_equiv_with_dim_unit
Axiom 2 states that any individual of type X is equivalent to a DescriptiveICE that possesses exactly one dimension and one unit. The table therefore stores the class X together with the two required class references; its primary key is the surrogate id while columns y and z are foreign keys that resolve to process records, satisfying the inverse direction required by the remaining axioms.

| id | x | y | z |
| id | x | y | z |
| m001 | pHValue | proc_in_01 | proc_out_01 |
| m002 | TemperatureReading | proc_in_02 | proc_out_02 |
| m003 | MassDetermination | proc_in_03 | proc_out_03 |
| m004 | ConductivityMeasure | proc_in_01 | proc_out_04 |
| m005 | VolumeQuantification | proc_in_04 | proc_out_03 |

### 1.2 t_process_min_one_input
Axiom 1 requires every process X to possess at least one input drawn from the measurement class. The table records the process class X and its mandatory input reference y; id is the primary key and y is a foreign key into t_measurement_equiv_with_dim_unit.

| id | x | y |
| id | x | y |
| proc_in_01 | SamplePreparation | m001 |
| proc_in_02 | ThermalEquilibration | m002 |
| proc_in_03 | GravimetricAnalysis | m003 |
| proc_in_04 | DilutionStep | m004 |

### 1.3 t_process_min_one_output
Axiom 3 requires every process X to possess at least one output drawn from the measurement class. The table records the process class X and its mandatory output reference y; id is the primary key and y is a foreign key into t_measurement_equiv_with_dim_unit.

| id | x | y |
| id | x | y |
| proc_out_01 | SamplePreparation | m001 |
| proc_out_02 | ThermalEquilibration | m002 |

### 1.4 t_process_max_one_operator
Axiom 4 permits a process X to possess at most one operator. The table records the process class X and an optional operator reference y; id is the primary key and y is a foreign key into t_measurement_equiv_with_dim_unit.

| id | x | y |

## 2 Cross-Join Demonstration

To obtain the dimension and unit of the output of the process that accepts input m001 and is operated by at most one operator, the following mental join is performed. Start with t_process_min_one_input where y = 'm001', yielding x = 'SamplePreparation' and id = 'proc_in_01'. Join to t_process_min_one_output on x = 'SamplePreparation', yielding y = 'm001'. Join that y value to t_measurement_equiv_with_dim_unit on id = 'm001', returning x = 'pHValue', y = 'proc_in_01', z = 'proc_out_01'. The joined row therefore states that SamplePreparation produces a pHValue whose dimension and unit are recorded under m001.

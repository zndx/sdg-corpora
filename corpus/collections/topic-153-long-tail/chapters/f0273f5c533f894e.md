# Modeling Service Traces, Addresses, and Ratings

This chapter defines three OWL-derived templates for processes in service and artifact properties. The templates are projected to a three-table relational schema that supports primary-key and foreign-key joins. Instances are drawn from engineering-consulting service records.

## 1. Template Definitions

The templates follow Manchester syntax axioms that restrict subclasses of bfo:0000015 and cco:Artifact. Each table below implements one template exactly, preserving slot types and the declared foreign-key constraints.

### 1.1 t_trace_in_service

This table embodies AXIOM 1 (trace_in_service). Column id is the primary key. Column y is a foreign key that must resolve to a row in t_schemaorg_place_address. A reader can join on y to retrieve the address at which a given process occurs.

| id | x | y |
|---|---|---|
| TR-001 | Dredging survey | AD-101 |
| TR-002 | Harbour assessment | AD-102 |
| TR-003 | Coastal modelling | AD-103 |
| TR-004 | Environmental review | AD-104 |
| TR-005 | Equipment calibration | AD-101 |

### 1.2 t_schemaorg_place_address

This table embodies AXIOM 2 (schemaorg_place_address). Column id is the primary key. Column y is a foreign key that must resolve to a row in t_trace_in_service. A reader can join on y to list every trace that references a given postal address.

| id | x | y |
|---|---|---|
| AD-101 | Atkins Group, London | TR-001 |
| AD-102 | Babtie Group, Glasgow | TR-002 |
| AD-103 | Delft Hydraulics, Delft | TR-003 |
| AD-104 | Dar al Handasah, Cairo | TR-004 |

### 1.3 t_schemaorg_review_rating

This table embodies AXIOM 3 (schemaorg_review_rating). Column id is the primary key. Column y is a foreign key that must resolve to a row in t_trace_in_service. A reader can join on y to obtain the rating attached to a given trace.

| id | x | y |
|---|---|---|
| RR-001 | 4.5 | TR-001 |
| RR-002 | 3.8 | TR-002 |
| RR-003 | 4.2 | TR-003 |
| RR-004 | 4.0 | TR-004 |
| RR-005 | 5.0 | TR-005 |

## 2. Cross-Table Query Example

To answer the multi-hop question “What rating is recorded for the dredging survey performed at the London address?”, start at t_schemaorg_place_address where x = 'Atkins Group, London' (AD-101). Follow the foreign key in t_trace_in_service.y = AD-101 to reach TR-001. Then follow the foreign key in t_schemaorg_review_rating.y = TR-001 to reach RR-001. The joined result row is:

id=RR-001, x=4.5, y=TR-001, trace_x=Dredging survey, address_x=Atkins Group, London

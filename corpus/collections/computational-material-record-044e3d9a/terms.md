# Grounding terms

The ontology universals this collection's chapters are written around (each an sdg: class, grounded in a BFO/CCO genus).

## Computational Material Record
- **genus**: `cco:ont00000995`
- **definition**: A digital record representing the input and output data generated by a computational materials science program for a specific material system.
- **attributes**: recordId, creationDate, fileSizeBytes, fileFormat, status, checksum
- **relations**: generatedBy→ComputationalCode, describes→MaterialSystem, processedBy→ParsingPipeline

## Computational Code
- **genus**: `cco:ont00000995`
- **definition**: A high-quality computational materials science software program used to generate input and output files for materials discovery.
- **attributes**: codeId, codeName, version, licenseType, developerGroup
- **relations**: produces→ComputationalMaterialRecord, runsOn→HighPerformanceComputerCenter

## Material System
- **genus**: `bfo:0000040`
- **definition**: A specific combination of chemical elements and structural configurations that is the subject of computational analysis.
- **attributes**: systemId, chemicalFormula, crystalSystem, spaceGroupNumber, latticeParameterA, latticeParameterB, latticeParameterC, formationEnergy
- **relations**: hasRecord→ComputationalMaterialRecord, exhibitsProperty→MaterialProperty

## Material Property
- **genus**: `bfo:0000016`
- **definition**: A measurable or computable characteristic of a material system, such as electronic band gap or thermal conductivity.
- **attributes**: propertyId, propertyName, numericValue, unitOfMeasure, confidenceInterval, measurementMethod
- **relations**: characterizes→MaterialSystem, derivedFrom→ComputationalMaterialRecord

## Parsing Pipeline
- **genus**: `bfo:0000015`
- **definition**: A computational process that converts inhomogeneous input and output files into a code-independent database format for analytics.
- **attributes**: pipelineId, pipelineName, startDateTime, endDateTime, status, recordsProcessed
- **relations**: processes→ComputationalMaterialRecord, runsOn→HighPerformanceComputerCenter, produces→ParsedDataStore

## High-Performance Computer Center
- **genus**: `bfo:0000004`
- **definition**: A physical or virtual facility providing the computational infrastructure for running materials science simulations and analytics.
- **attributes**: centerId, centerName, location, totalComputeNodes, peakPerformanceFlops, operationalStatus
- **relations**: hosts→ComputationalCode, executes→ParsingPipeline, supports→BigDataAnalyticsTool

## Big Data Analytics Tool
- **genus**: `bfo:0000015`
- **definition**: A computational process employing data mining, statistical analysis, or machine learning to extract hidden structures, correlations, and novel materials from the materials data pool.
- **attributes**: toolId, toolName, algorithmType, startDate, endDate, status, novelMaterialsDiscovered
- **relations**: analyzes→ParsedDataStore, discovers→MaterialSystem, runsOn→HighPerformanceComputerCenter

## Parsed Data Store
- **genus**: `cco:ont00000995`
- **definition**: A code-independent database structure containing normalized and converted materials data ready for analytics and visualization.
- **attributes**: storeId, storeName, totalRecords, lastUpdated, storageSizeGB, dataIntegrityStatus
- **relations**: contains→ComputationalMaterialRecord, feeds→BigDataAnalyticsTool, supports→VisualizationService

## Visualization Service
- **genus**: `bfo:0000015`
- **definition**: A centralized computational service enabling users to interactively perform data visualization on materials data without local hardware dependencies.
- **attributes**: serviceId, serviceName, endpointUrl, uptimePercentage, maxConcurrentUsers, activeStatus
- **relations**: visualizes→ParsedDataStore, runsOn→HighPerformanceComputerCenter

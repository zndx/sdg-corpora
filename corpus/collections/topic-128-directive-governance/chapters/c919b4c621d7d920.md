# Chapter 7: Directive Governance Entities in Municipal Energy Compliance Audits

This chapter defines five relational tables that instantiate OWL axioms for directive information content entities, designative subclasses, verification processes, and priority assignments. The tables support cross-table joins that trace policy review cycles, requirement priorities, and evidence-producing verifications within audit records for net-zero energy homes.

## 1 Scope and Schema Overview

The schema models compliance documentation for the Energuide-rated Windsor Park NZE Home and the Parsons, Kansas fiscal-year audit process. Each table directly implements one axiom. Primary keys are surrogate identifiers; foreign keys enforce subclass membership and evidence linkage. Four to six rows per table suffice to demonstrate multi-hop queries such as “which priority applies to the policy reviewed by a given verification process.”

## 1.1 Designative Subclass Instances

Table t_designative_subclass_basic embodies Axiom 2. Column id is the primary key; column x holds the designative ICE class name. Rows serve as targets for all foreign-key references in subsequent tables.

```sql
CREATE TABLE t_designative_subclass_basic (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

## 1.3 Policies and Their Review Cycles

Table t_policy_with_review_cycle embodies Axiom 1. Column id is the primary key; column x names the policy class; column y is a foreign key referencing t_designative_subclass_basic.id. A join on y yields the review-cycle class for any policy.

```sql
CREATE TABLE t_policy_with_review_cycle (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_designative_subclass_basic(id)
);
```

## 2 Cross-Join Demonstration

To determine the priority of the requirement satisfied by the verification process that produces evidence for the NetZeroEnergyPolicy, execute the following mental join path:

- Start at PRC-001 (NetZeroEnergyPolicy) → y = DSC-001.
- Locate RHP-001 (EnerguideZeroGJRequirement) whose y = DSC-002.
- Locate VME-001 (EnerguideAuditProcess) whose y = DSC-003.
- The joined row is: policy = NetZeroEnergyPolicy, requirement = EnerguideZeroGJRequirement, priority = HighPriority, verification = EnerguideAuditProcess, evidence = VerificationEvidence.

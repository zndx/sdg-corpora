# Chapter 7: Relational Projections of Directive ICE Ontologies for ISO 27001 and PCI DSS Audit Trails

This chapter presents five tables that instantiate the provided OWL axioms as a queryable schema for audit-trail records of information-security controls. The tables support cross-table joins that trace how a control class addresses a risk class, satisfies an annex reference, and meets an equivalent requirement specification.

## 1 Schema Overview and Primary-Key Structure

The schema comprises exactly the five tables defined by the axioms. Each table uses an explicit primary-key column named `id`. Foreign-key columns implement the slot-type references declared in the axioms, enabling two-hop and three-hop joins that answer questions such as “which PCI DSS requirement is satisfied by a control that addresses a given threat class and also appears in ISO 27001 Annex A.”

t_control_only_addresses_threat_class.y = t_iso27001_annexa_subclass.id

# Chapter 4. Directive Controls in Information Security Governance

This chapter defines a relational representation of directive controls drawn from ISO 27001 Annex A and PCI DSS. The schema captures subclass relationships, risk-addressing properties, and requirement specifications using five tables that implement the axioms supplied in Section 2. All column values are instances of the declared slot types; foreign-key constraints enforce the permitted joins.

## 1 Schema Overview

The five tables materialise the five axioms. Primary keys are stable identifiers for each class expression. Foreign keys implement the existential and universal restrictions on the properties `iso27001AnnexA`, `addressesRisk`, `pciDssRequirement`, `specifies` and `appliesTo`. Cross-table queries therefore reconstruct the full Manchester syntax expressions.

## 2 Table Definitions

t_iso27001_annexa_subclass embodies axiom 1. Column `id` is the primary key. Column `y` is a foreign key referencing `t_control_only_addresses_threat_class.id`, recording the risk class that completes the `iso27001AnnexA` restriction. A reader can therefore join on `y` to retrieve every Annex A control that addresses a given threat class.

t_control_only_addresses_threat_class embodies axiom 2. Column `id` is the primary key. Column `y` is a foreign key referencing `t_iso27001_annexa_subclass.id`, closing the universal restriction on `addressesRisk`. The mutual foreign-key pair between this table and t_iso27001_annexa_subclass permits verification that every control is linked to exactly one threat class.

## 3 Cross-Join Example

To determine which PCI DSS requirement is satisfied by the control that addresses the risk linked to Annex A control A.5.1.1, the following path is traversed:

1. Start at `t_iso27001_annexa_subclass` row IAS-001 (`y` = CTR-003).
2. Join to `t_control_only_addresses_threat_class` on CTR-003.
3. Join to `t_pci_dss_requirement` on CTR-003 (`y`).

The resulting joined row is:

IAS-001 | A.5.1.1 | CTR-003 | LoggingRetention | PCI-003 | Req-10.7

This single traversal answers the multi-hop question “Which PCI DSS requirement governs the logging control that addresses the threat recorded for Annex A control A.5.1.1?”

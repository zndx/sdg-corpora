# Audit Trail Ontologies for Compliance Verification

This chapter defines five ontological templates that formalize how artifacts and processes support or attest to descriptive claims in regulated data environments. The templates are realized as a fixed relational schema whose rows record concrete instances drawn from an audit trail system that tracks lawful data processing under GDPR. Primary keys identify each recorded instance; shared values in the x and y columns enable cross-table joins that reconstruct multi-hop provenance from raw events to compliance assertions.

## 1. Trace Support for Descriptive Claims

Axiom 1 is embodied by table t_trace_supports_claim. The column id is the primary key; column x holds the identifier of a process class that supports a DescriptiveICE claim. Rows in this table can be joined to rows in t_attestation_about_compliance_claim by matching x values that appear in both tables.

```sql
CREATE TABLE t_trace_supports_claim (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

| id | x |
|----|---|
| trace-001 | DataAccessTrace |
| trace-002 | ConsentReceiptTrace |
| trace-003 | RetentionReviewTrace |
| trace-004 | ExportControlTrace |
| trace-005 | DeletionAuditTrace |
| trace-006 | AccessReviewTrace |

## 1.1 Lawful Basis Declarations

Axiom 2 is embodied by table t_gdpr_lawful_basis. The column id is the primary key; column x references a DirectiveICE instance and column y records the specific lawful basis class. The y column functions as a foreign reference that can be joined with x values from t_column_lineage_for_compliance_claim when both tables record the same compliance claim identifier.

```sql
CREATE TABLE t_gdpr_lawful_basis (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

| id | x | y |
|----|---|---|
| basis-001 | ConsentDirective | GDPRArt6Consent |
| basis-002 | ContractDirective | GDPRArt6Contract |
| basis-003 | LegalObligationDirective | GDPRArt6LegalObligation |
| basis-004 | VitalInterestsDirective | GDPRArt6VitalInterests |
| basis-005 | PublicTaskDirective | GDPRArt6PublicTask |
| basis-006 | LegitimateInterestsDirective | GDPRArt6LegitimateInterests |

## 1.2 Column Lineage Supporting Claims

Axiom 3 is embodied by table t_column_lineage_for_compliance_claim. The column id is the primary key; column x holds the identifier of an Artifact whose lineage supports a DescriptiveICE claim. Values of x may be joined with x values in t_kernel_anomaly_supports_claim to link lineage records to anomaly detections that affect the same claim.

```sql
CREATE TABLE t_column_lineage_for_compliance_claim (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

| id | x |

| lineage-003 | HealthRecordIdColumn |
| lineage-004 | MarketingOptInColumn |
| lineage-005 | PaymentMethodColumn |
| lineage-006 | LocationHistoryColumn |

## 2. Kernel Anomaly Records

Axiom 4 is embodied by table t_kernel_anomaly_supports_claim. The column id is the primary key; column x identifies an Artifact whose anomaly record supports a DescriptiveICE claim. The table shares x value space with t_column_lineage_for_compliance_claim, permitting a two-table join that retrieves both lineage and anomaly data for a given claim.

```sql
CREATE TABLE t_kernel_anomaly_supports_claim (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

## 2.1 Attestation of Compliance Claims

Axiom 5 is embodied by table t_attestation_about_compliance_claim. The column id is the primary key; column x identifies a process that attests to a DescriptiveICE claim. The table shares x value space with t_trace_supports_claim, enabling a join that pairs supporting traces with their corresponding attestations.

```sql
CREATE TABLE t_attestation_about_compliance_claim (
  id VARCHAR(255),

);

Start with t_column_lineage_for_compliance_claim row lineage-001 (x = CustomerEmailColumn). Locate the matching x in t_kernel_anomaly_supports_claim (anomaly-001). The shared x value CustomerEmailColumn appears in t_gdpr_lawful_basis as basis-001, whose y column yields GDPRArt6Consent.

# Chapter 12: Modeling GDPR Attestations and Audit Controls in Relational Form

This chapter defines a minimal relational schema that realizes five ontology axioms for directive governance. The schema supports attestation signing, GDPR article subclassing, evidence attachment, data-subject-right grants, and audit classification. All tables follow the deterministic projections of the axioms. Primary keys are string identifiers. Foreign keys enforce the subclass and evidence relationships required by the Manchester syntax forms.

## 1 Schema Overview

The five tables correspond one-to-one with the five axioms. Three tables contain foreign-key columns that permit two-hop and three-hop joins. The domain chosen is audit-trail recording for a primary-school GDPR compliance program, consistent with the governance setting of the source corpus. Column values are drawn from the same corpus register: formal identifiers, article references, and evidence citations.

### 1.1 Table t_attestation_signed_by

This table embodies Axiom 1 (attestation_signed_by). Column id is the primary key. Column x stores the attestation class that is declared a subclass of bfo:0000015 and signed by a cco:Person.

| att-002 | DataProcessingRecordAttestation |

## 2 Cross-Join Demonstration

A multi-hop question is answered by successive foreign-key traversal. Question: which supporting evidence backs the attestation that grants the right to erasure and was signed under Article 17?

Start at t_gdpr_data_subject_right where x = RightToErasureGrant; read y = att-003.  
Join t_attestation_signed_by on id = att-003.  
Join t_gdpr_article_subclass on y = att-003; read id = gdpr-004.  
Join t_attestation_with_supporting_evidence on y = gdpr-004; read x = DeletionCertificate.

Result row after the three joins:  
(RightToErasureGrant, att-003, gdpr-004, DeletionCertificate)

The same path can be expressed in SQL as:

```sql
SELECT dsr.x, att.id, gac.id, awe.x
FROM t_gdpr_data_subject_right dsr
JOIN t_attestation_signed_by att ON dsr.y = att.id
JOIN t_gdpr_article_subclass gac ON gac.y = att.id
JOIN t_attestation_with_supporting_evidence awe ON awe.y = gac.id
WHERE dsr.x = 'RightToErasureGrant';
```

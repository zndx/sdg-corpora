# Directive Governance Ontologies in Health Service Audit Trails

This chapter defines five core ontological templates for directive governance and control structures. It projects each template into a deterministic relational schema and populates the resulting tables with instances drawn from community accountability audits of maternal, neonatal and child health services. The schemas support cross-table joins that recover multi-hop provenance between attestations, controls, addressed risks and conducting persons.

## 1 Scope and axiomatic grounding

The templates are expressed in OWL Manchester syntax and anchored to BFO and CCO. Each template is materialised as a table whose columns correspond exactly to the declared slots. Primary keys are opaque identifiers; foreign-key semantics arise when values in the x or y columns match identifiers in other tables, enabling reconstruction of evidence chains and risk-addressing relations.

### 1.1 Attestation with supporting evidence

This table embodies AXIOM 1. Column id is the primary key; columns x and y are class references whose values may be joined to identifiers in t_control_addresses_risk or t_control_with_evidence_requirement.

```sql
SELECT a.x, a.y, r.y
FROM t_attestation_with_supporting_evidence a
JOIN t_control_addresses_risk r ON a.y = r.id;
```

# Chapter 7: Directive Governance in Municipal Compliance Audit Trails

This chapter presents five relational tables that instantiate five axioms from the directive-governance ontology family. The tables record policies, requirements, and attestations that govern municipal committee activity. Primary keys are stable identifiers; foreign-key columns hold identifiers drawn from the same identifier space, enabling two- and three-table joins that recover jurisdiction, scope, enforcer, signer, and target.

## 1 Policy Jurisdiction and Scope

Axiom 1 states that a policy is equivalent to a directive information content entity that has a jurisdiction and governs a scope. Table t_policy_equiv_jurisdiction_and_scope therefore stores one row per policy; column id is the primary key, while y and z are foreign keys that reference jurisdiction and scope class identifiers respectively.

## 2 Cross-Join Example

To recover the enforcer of the policy that governs the scope of a given requirement, join t_policy_equiv_jurisdiction_and_scope on x with t_policy_min_one_enforcer on x, then join the resulting y with the requirement table on scope overlap. The query

```
SELECT p.x AS policy, e.y AS enforcer, r.z AS target
FROM t_policy_equiv_jurisdiction_and_scope p
JOIN t_policy_min_one_enforcer e ON p.x = e.x
JOIN t_requirement_equiv_specifies_target r ON p.z = r.y
WHERE r.z = 'AppliesTo148MartineAve';
```

returns the single joined row (HousingPolicy2020, PersonDamonMaher, AppliesTo148MartineAve).

# Directive Governance in Data Protection Compliance

This chapter presents five tables that encode the slot structures of five OWL axioms governing directive information content entities. The tables support cross-table joins that resolve multi-hop queries over lawful bases, jurisdictions, evidence requirements, and claim support.

## 1. Axiom-to-Table Mapping

Each table is introduced by the axiom whose slot types determine its columns and foreign-key constraints.

### 1.1 Lawful Basis Table

Axiom 1 states that a directive class X has lawful basis Y. The primary key is the synthetic identifier id; the foreign key y references a jurisdiction-bearing policy, enabling a join that pairs each lawful basis with its governing policy.

```sql
CREATE TABLE t_gdpr_lawful_basis (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_policy_with_jurisdiction(id)
);
```

| id | x | y |
|----|---|---|
| lb-001 | Consent | pol-001 |
| lb-002 | Contract | pol-002 |
| lb-003 | LegalObligation | pol-003 |
| lb-004 | VitalInterests | pol-001 |
| lb-005 | PublicTask | pol-004 |
| lb-006 | LegitimateInterests | pol-002 |

### 1.2 Policy-with-Jurisdiction Table

Axiom 2 states that a directive class X has jurisdiction Y. The primary key is id; the foreign key y references a lawful-basis record, closing the mutual reference required by the paired axioms.

```sql
CREATE TABLE t_policy_with_jurisdiction (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_gdpr_lawful_basis(id)
);
```

| id | x | y |
|----|---|---|
| pol-001 | GDPR-Art6 | lb-001 |
| pol-002 | GDPR-Art6 | lb-002 |
| pol-003 | GDPR-Art6 | lb-003 |
| pol-004 | GDPR-Art6 | lb-005 |
| pol-005 | CCPA-1798 | lb-006 |

### 1.3 Trace-Supports-Claim Table

Axiom 3 states that a process X supports a descriptive claim. The sole column id serves as primary key; no foreign key is defined, so the table functions as a leaf node that other tables may reference indirectly through claim identifiers stored in x.

```sql
CREATE TABLE t_trace_supports_claim (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

| id | x |
|----|---|
| tr-001 | Claim-ConsentRecorded |
| tr-002 | Claim-ContractSigned |
| tr-003 | Claim-ObligationMet |
| tr-004 | Claim-InterestAssessed |
| tr-005 | Claim-TaskDocumented |

### 1.4 Control-with-Evidence-Requirement Table

Axiom 4 states that a directive class X requires evidence Y. The primary key is id; the foreign key y references a lawful-basis record, allowing a join that lists every control together with the lawful basis it must evidence.

```sql
CREATE TABLE t_control_with_evidence_requirement (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_gdpr_lawful_basis(id)
);
```

| id | x | y |
|----|---|---|
| ctl-001 | ConsentCapture | lb-001 |
| ctl-002 | ContractArchive | lb-002 |
| ctl-003 | ObligationLog | lb-003 |
| ctl-004 | InterestTest | lb-006 |
| ctl-005 | TaskRegister | lb-005 |

### 1.5 Policy-Equivalent-Jurisdiction-and-Scope Table

Axiom 5 defines an equivalence that conjoins jurisdiction and scope. The primary key is id; the foreign key y references a lawful-basis record, permitting a join that recovers both jurisdiction and scope for each equivalent policy class.

```sql
CREATE TABLE t_policy_equiv_jurisdiction_and_scope (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  z VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_gdpr_lawful_basis(id)
);
```

| peq-001 | GDPR-Art6-Consent | lb-001 | ProcessingEU |
| peq-002 | GDPR-Art6-Contract | lb-002 | ProcessingEU |
| peq-003 | GDPR-Art6-Obligation | lb-003 | ProcessingEU |

## 2. Cross-Join Demonstration

To determine which evidence requirement applies to a policy whose jurisdiction is recorded under lawful basis lb-001, join t_policy_with_jurisdiction to t_control_with_evidence_requirement on the shared lawful-basis column:

```sql
SELECT p.x AS policy, c.x AS control
FROM t_policy_with_jurisdiction p
JOIN t_control_with_evidence_requirement c ON p.y = c.y
WHERE p.y = 'lb-001';
```

Result row: policy = GDPR-Art6, control = ConsentCapture.

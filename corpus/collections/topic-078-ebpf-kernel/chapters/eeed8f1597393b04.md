# Chapter 9: Directive Information Content Entities in Regulatory Audit Trails

This chapter specifies five relational tables that realize the slot structures of five OWL axioms governing DirectiveICE subclasses. The tables record policies, lawful bases, jurisdictions, evidence requirements, and claim-supporting traces within an audit system for cross-border data processing compliance. All column values are instances of the declared slot types; foreign-key constraints enforce the existential restrictions stated in the axioms.

## 1. Axiom Embodiment and Table Definitions

### 1.1 t_policy_with_jurisdiction

This table embodies AXIOM 2. Column id is the primary key. Column y is a foreign key referencing t_gdpr_lawful_basis(id) and records the jurisdiction class required by the policy class in column x. A reader can join on y to retrieve the lawful basis that must be present for any policy asserted under that jurisdiction.

| id          | x                              | y            |
|-------------|--------------------------------|--------------|
| POL-001     | GDPR-Controller-Policy         | LB-001       |
| POL-002     | GDPR-Processor-Agreement       | LB-002       |
| POL-003     | Cross-Border-Transfer-Policy   | LB-003       |
| POL-004     | Data-Subject-Rights-Policy     | LB-001       |
| POL-005     | Breach-Notification-Policy     | LB-004       |

### 1.2 t_gdpr_lawful_basis

This table embodies AXIOM 1. Column id is the primary key. Column y is a foreign key referencing t_policy_with_jurisdiction(id) and records the policy class that supplies the lawful basis class named in column x. A reader can join on y to obtain the jurisdiction under which the lawful basis is operative.

| id          | x                    | y            |
|-------------|----------------------|--------------|
| LB-001      | Consent              | POL-001      |
| LB-002      | Contract             | POL-002      |
| LB-003      | Legal-Obligation     | POL-003      |

| LB-005      | Vital-Interests      | POL-001      |

### 1.3 t_control_with_evidence_requirement

This table embodies AXIOM 4. Column id is the primary key. Column y is a foreign key referencing t_gdpr_lawful_basis(id) and records the lawful basis class whose satisfaction must be evidenced by the control class named in column x. A reader can join on y to list every control that must produce evidence for a given lawful basis.

| id          | x                              | y            |
|-------------|--------------------------------|--------------|
| CTL-001     | Consent-Recording-Control      | LB-001       |
| CTL-002     | Contract-Archival-Control      | LB-002       |

| CTL-004     | Interest-Balancing-Control     | LB-004       |
| CTL-005     | Rights-Response-Control        | LB-001       |
| CTL-006     | Transfer-Safeguard-Control     | LB-003       |

### 1.4 t_policy_equiv_jurisdiction_and_scope

This table embodies AXIOM 5. Column id is the primary key. Column y is a foreign key referencing t_gdpr_lawful_basis(id). Columns y and z together assert the necessary and sufficient conditions of jurisdiction and scope for the policy class in column x. A reader can join on y to verify that a policy’s jurisdiction is consistent with its declared lawful basis.

| id          | x                              | y            | z                     |
|-------------|--------------------------------|--------------|-----------------------|
| PEQ-001     | GDPR-Controller-Policy         | LB-001       | EU-Member-States      |
| PEQ-002     | GDPR-Processor-Agreement       | LB-002       | EEA-Processing        |
| PEQ-003     | Cross-Border-Transfer-Policy   | LB-003       | Third-Country-List    |
| PEQ-004     | Data-Subject-Rights-Policy     | LB-001       | All-Data-Subjects     |

### 1.5 t_trace_supports_claim

## 2. Cross-Join Demonstration

To determine the jurisdiction and required evidence for the lawful basis asserted by the controller policy, execute the following mental join. Start with POL-001 in t_policy_with_jurisdiction. Its y value LB-001 references t_gdpr_lawful_basis. That row’s x value Consent joins to t_control_with_evidence_requirement on y, yielding CTL-001 and CTL-005. The same LB-001 row also joins to t_policy_equiv_jurisdiction_and_scope on y, confirming scope EU-Member-States. The resulting joined tuple is therefore:

POL-001, GDPR-Controller-Policy, LB-001, Consent, CTL-001, CTL-005, EU-Member-States.

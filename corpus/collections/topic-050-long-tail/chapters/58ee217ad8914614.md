# Evidence Structures for PCI DSS Requirement Modeling

This chapter defines five ontological templates that relate directives, descriptive statements, baseline rates, and evidence relations. The templates are projected to a five-table relational schema whose foreign-key graph supports two- and three-hop joins. All rows are drawn from a PCI DSS compliance audit of cardholder data environments conducted between 1 March 2023 and 31 May 2023.

## 1. Template Definitions and Schema Projection

Five Manchester OWL axioms are used. Each axiom is realized by one table. Primary keys are opaque identifiers; foreign keys implement the “some” restrictions stated in the axioms.

### 1.1 t_evidence_correlated_with

The axiom states that any descriptive ICE whose evidence is correlated with another descriptive ICE is recorded in this table. Column id is the primary key. Column y is a foreign key to t_lift_with_baseline_rate.id, allowing a reader to retrieve the lift value that quantifies the correlation.

| id  | x                  | y   |
|-----|--------------------|-----|
| ec1 | EvidenceSet-12.3 | l1  |
| ec2 | EvidenceSet-12.4 | l2  |
| ec3 | EvidenceSet-8.2  | l3  |
| ec4 | EvidenceSet-8.3  | l1  |
| ec5 | EvidenceSet-3.4  | l4  |

### 1.2 t_lift_with_baseline_rate

The axiom states that any descriptive ICE that carries a baseline rate is recorded here. Column id is the primary key. Column y is a foreign key to t_evidence_correlated_with.id, closing the correlation–lift cycle.

| id | x             | y   |
|----|---------------|-----|
| l1 | Lift-12.3     | ec1 |
| l2 | Lift-12.4     | ec2 |
| l3 | Lift-8.2      | ec3 |
| l4 | Lift-3.4      | ec5 |
| l5 | Lift-10.1     | ec1 |

### 1.3 t_pci_dss_requirement

The axiom states that any directive ICE that is also a PCI DSS requirement is recorded here. Column id is the primary key. Column y is a foreign key to t_lift_with_baseline_rate.id, linking each requirement to its supporting lift calculation.

| id  | x       | y   |
|-----|---------|-----|
| p1  | Req-12  | l1  |
| p2  | Req-8   | l3  |
| p3  | Req-3   | l4  |
| p4  | Req-10  | l5  |
| p5  | Req-12a | l2  |

### 1.4 t_pignistic_transformation

The axiom states that any descriptive ICE that possesses a pignistic transform is recorded here. Column id is the primary key. Column y is a foreign key to t_lift_with_baseline_rate.id.

| id   | x               | y   |
|------|-----------------|-----|
| pt1  | Pignistic-12.3  | l1  |
| pt2  | Pignistic-8.2   | l3  |
| pt3  | Pignistic-3.4   | l4  |
| pt4  | Pignistic-10.1  | l5  |
| pt5  | Pignistic-12.4  | l2  |

### 1.5 t_evidence_independent_of

The axiom states that any descriptive ICE whose evidence is independent of another descriptive ICE is recorded here. Column id is the primary key. Column y is a foreign key to t_lift_with_baseline_rate.id.

| id   | x                 | y   |
|------|-------------------|-----|
| ei1  | Independence-12.3 | l1  |
| ei2  | Independence-8.2  | l3  |
| ei3  | Independence-3.4  | l4  |
| ei4  | Independence-10.1 | l5  |
| ei5  | Independence-12.4 | l2  |

# Chapter 4: Relational Projection of ISO 27001 Directive and Attestation Axioms

1 Scope

This chapter specifies the relational tables that realize five OWL axioms for ISO 27001 clause subclassing, requirement equivalence, and attestation signing within an ISMS audit record system. Each table follows the deterministic schema derived from the corresponding axiom slot structure. Primary-key and foreign-key columns enable deterministic cross-table joins that answer multi-hop compliance queries.

1.1 t_requirement_equiv_specifies_target

Axiom 4 is embodied by this table. Column id is the primary key. Column y is a foreign key referencing t_iso27001_clause_subclass(id). Column z records the target class to which the requirement applies. A reader can join this table to t_iso27001_clause_subclass on y to retrieve the clause identifier that participates in the equivalence definition.

```sql
CREATE TABLE t_requirement_equiv_specifies_target (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  z VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_iso27001_clause_subclass(id)
);
```

1.2 t_iso27001_clause_subclass

Axiom 1 is embodied by this table. Column id is the primary key. Column y is a foreign key referencing t_requirement_equiv_specifies_target(id). The structure records that each clause subclass X is a DirectiveICE that references a specific ISO 27001 clause Y.

```sql
CREATE TABLE t_iso27001_clause_subclass (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_requirement_equiv_specifies_target(id)
);
```

# Chapter 4: DirectiveICE Projections for HIPAA and PCI DSS Attestations

This chapter defines five relational tables that instantiate the provided OWL axioms for DirectiveICE subclasses and supporting processes. The tables encode class references as entity identifiers and enforce foreign-key links that permit traversal from safeguard directives to attestation records and back. All column values derive from formal compliance documentation patterns observed in board and examination records.

## 1. Axiom Mapping to Schema

Each axiom is realized by one table. Primary keys uniquely identify directive instances. Foreign keys implement the existential restrictions on supporting evidence or safeguard targets. The circular reference between administrative safeguards and attestations mirrors the mutual dependence stated in the Manchester syntax.

# Chapter 4: Verification Processes in Laboratory Information Management

This chapter defines the subclass relation of verification processes under bfo:0000015 and demonstrates the mandatory production of at least one evidence instance through a minimal relational schema. The model supports direct foreign-key traversal between process identifiers and evidence identifiers.

## 1 Domain Scope

The selected domain is laboratory sample verification. Each verification activity is recorded as a process instance. Evidence items are produced by these processes and remain traceable through shared identifiers. All column values are drawn from controlled laboratory vocabularies.

## 1.1 Table t_sample

This table records individual samples that enter verification processes. Column sample_id is the primary key. No foreign keys are present. A reader can join sample_id values to any downstream process table that references the same identifier.

| sample_id | material | received_date | volume_ml |
|-----------|----------|---------------|-----------|
| S-1001    | water    | 2024-01-10    | 250       |
| S-1002    | air      | 2024-01-11    | 500       |
| S-1003    | gas      | 2024-01-12    | 100       |
| S-1004    | light oil| 2024-01-13    | 300       |

## 1.2 Table t_evidence

This table records discrete evidence artefacts generated by verification processes. Column evidence_id is the primary key. No foreign keys are present. Evidence rows supply the y values required by the verification axiom.

| evidence_id | type          | storage_location | retention_days |
|-------------|---------------|------------------|----------------|
| E-2001      | chromatogram  | Cabinet A3       | 365            |
| E-2002      | sensor_log    | Server Rack 2    | 730            |
| E-2003      | visual_record | Archive Room     | 180            |
| E-2004      | pressure_log  | Cabinet A3       | 365            |

## 1.3 Table t_verification_min_one_evidence

This table directly embodies axiom verification_min_one_evidence. Column id is the primary key. Column x references a process class instance. Column y is a foreign key that must resolve to an evidence_id in t_evidence, enforcing the existential restriction “producesEvidence min 1”. Cross-table lookup of y yields the concrete evidence record for any given process.

| id       | x                  | y      |
|----------|--------------------|--------|
| V-3001   | pressure_test      | E-2001 |
| V-3002   | viscosity_check    | E-2002 |
| V-3003   | temperature_scan   | E-2003 |
| V-3004   | flow_calibration   | E-2004 |
| V-3005   | pressure_test      | E-2002 |

## 2 Cross-Join Demonstration

Question: which evidence record is produced by the pressure_test process performed on sample S-1001?

Walk the keys: locate x = “pressure_test” in t_verification_min_one_evidence (rows V-3001 and V-3005). Read the corresponding y values (E-2001, E-2002). Join each y to t_evidence on evidence_id. Result rows:

- V-3001 → E-2001 (chromatogram, Cabinet A3)

# Chapter 7: Belief Structures over Laboratory Measurement Continuants

This chapter specifies five relational tables that realize selected OWL axioms drawn from BFO and CCO extensions for descriptive information content entities. The tables encode independent continuants, mass functions with normalization, distinctness ratios, pignistic transforms, and processes restricted to at most one operator. All column values are drawn from laboratory sample-analysis records; primary-key and foreign-key constraints enforce the slot restrictions stated in each axiom.

## 1. Independent Continuants as Measurement Entities

Axiom 1 states that any class X is a subclass of bfo:IndependentContinuant. Table t_subclass_to_independent_continuant therefore stores only entity references that remain unchanged across measurement events. Column id is the primary key; column x holds the class label.

```sql
CREATE TABLE t_subclass_to_independent_continuant (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

|----|---|
| ic-001 | SampleContainer |
| ic-002 | AnalyticalBalance |
| ic-003 | CalibrationWeightSet |
| ic-004 | pHProbe |
| ic-005 | TemperatureLogger |

## 1.1 Mass Functions with Explicit Normalization

Axiom 2 asserts that class X is a cco:DescriptiveICE possessing a normalization constant Y. Table t_mass_function_with_normalization records each mass function together with its required normalization reference. Column id is the primary key; column y is a foreign key to t_column_distinctness.id.

```sql
CREATE TABLE t_mass_function_with_normalization (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_column_distinctness(id)
);
```

| id | x | y |
|----|---|---|
| mf-101 | MassFunction_SampleVolume | cd-201 |
| mf-102 | MassFunction_Conductivity | cd-202 |
| mf-103 | MassFunction_MassDelta | cd-203 |

| mf-105 | MassFunction_Alkalinity | cd-205 |

## 1.2 Column Distinctness Ratios

Axiom 3 states that class X is a cco:DescriptiveICE carrying a distinctness ratio Y. Table t_column_distinctness stores the ratio reference. Column id is the primary key; column y is a foreign key to t_mass_function_with_normalization.id, establishing the mutual referential constraint between the two tables.

```sql
CREATE TABLE t_column_distinctness (
  id VARCHAR(255),

  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_mass_function_with_normalization(id)
```

## 1.3 Pignistic Transformations

Axiom 4 declares that class X possesses a pignistic transform Y. Table t_pignistic_transformation records each transformation and its source mass function. Column id is the primary key; column y references t_mass_function_with_normalization.id.

```sql
CREATE TABLE t_pignistic_transformation (
  id VARCHAR(255),
```

## 1.4 Processes Limited to One Operator

Axiom 5 restricts any process X to at most one operator Y. Table t_process_max_one_operator captures this cardinality constraint. Column id is the primary key; column y references t_mass_function_with_normalization.id.

```sql
CREATE TABLE t_process_max_one_operator (
  id VARCHAR(255),
```

## 2. Cross-Join Demonstration

A multi-hop query retrieves the pignistic transform associated with the normalization constant of the mass function used by a given process. The following mental join traverses t_process_max_one_operator → t_mass_function_with_normalization → t_pignistic_transformation on the shared mass-function identifier.

Process pr-401 (“TitrationRun”) references mf-105. Mass function mf-105 references distinctness ratio cd-205, which in turn references mf-105, confirming the cycle. The same mf-105 is referenced by pignistic transform pt-305 (row omitted from the five-row sample for brevity but present in the full population). The joined result row is therefore:

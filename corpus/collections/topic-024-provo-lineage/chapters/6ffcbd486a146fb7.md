# Market Data Validation Using Descriptive Claims

This chapter defines three ontological templates for representing priced artifacts and the descriptive claims made about them. The templates are realized as a minimal relational schema consisting of three tables. Primary keys identify individuals; foreign keys encode the existential restrictions required by each axiom. Cross-table joins recover multi-hop facts such as “which priced product is referenced by an attribute-bearing claim.”

## 1 Ontology Axioms and Their Relational Projections

Three axioms are used. The first states that an artifact class carries a price. The second states that a descriptive information content entity exists. The third states that such an entity must reference at least one priced artifact. Each axiom is materialized by one table whose column signatures and foreign-key constraints are fixed by the axiom’s slot types.

### 1.1 t_outlier_claim_basic

The table embodies axiom 2. Column id is the primary key naming the descriptive information content entity. Column x holds the class that satisfies the axiom. No foreign keys are present because the axiom introduces no existential restriction.

```sql
CREATE TABLE t_outlier_claim_basic (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

Example rows:

| id          | x                     |
|-------------|-----------------------|
| claim001    | PriceOutlierClaim     |
| claim002    | PriceOutlierClaim     |
| claim003    | PriceOutlierClaim     |
| claim004    | PriceOutlierClaim     |
| claim005    | PriceOutlierClaim     |

### 1.2 t_schemaorg_product_price

The table embodies axiom 1. Column id is the primary key naming the priced artifact. Column x names the artifact class. Column y is a foreign key referencing t_outlier_claim_basic(id), thereby recording that the artifact participates in a descriptive claim. A reader can join the two tables to list every artifact that appears inside a given claim.

```sql
CREATE TABLE t_schemaorg_product_price (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_outlier_claim_basic(id)
);
```

Example rows:

| id       | x               | y        |
|----------|-----------------|----------|
| prod001  | CrudeOilBarrel  | claim001 |
| prod002  | NaturalGasMMBtu | claim001 |
| prod003  | CrudeOilBarrel  | claim002 |
| prod004  | LNGMetricTon    | claim003 |
| prod005  | CrudeOilBarrel  | claim004 |
| prod006  | NaturalGasMMBtu | claim005 |

### 1.3 t_outlier_claim_min_one_attribute

The table embodies axiom 3. Column id is the primary key naming the descriptive claim. Column x again names the claim class. Column y is a foreign key referencing t_schemaorg_product_price(id), satisfying the “min 1” restriction. Joining this table to t_schemaorg_product_price and then to t_outlier_claim_basic yields the full chain from claim to priced artifact.

```sql
CREATE TABLE t_outlier_claim_min_one_attribute (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_schemaorg_product_price(id)
);
```

Example rows:

| id         | x                     | y       |
|------------|-----------------------|---------|
| attr001    | PriceOutlierClaim     | prod001 |
| attr002    | PriceOutlierClaim     | prod003 |
| attr003    | PriceOutlierClaim     | prod004 |
| attr004    | PriceOutlierClaim     | prod006 |

## 2 Cross-Join Demonstration

To recover every priced artifact that participates in an attribute-bearing claim, execute the following mental join:

```
t_outlier_claim_min_one_attribute.y
→ t_schemaorg_product_price.id
→ t_schemaorg_product_price.y
→ t_outlier_claim_basic.id
```

For claim001 the path yields:

- attr001 → prod001 → claim001  
- The artifact CrudeOilBarrel (prod001) is therefore asserted by the descriptive claim claim001 and carries a price attribute.

The same path applied to claim002 returns only prod003, confirming that the min-1 restriction is satisfied while still allowing multiple priced artifacts to be referenced by distinct claims.

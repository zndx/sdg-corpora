# Modeling Descriptive Information Content Entities in Anomaly Audit Trails

This chapter presents three ontological templates for representing evidence-based claims about outliers. The templates are realized as a minimal relational schema supporting multi-table joins that recover statistical context, baseline rates, and attribute sets from audit records.

## 1 Ontological Patterns for Evidence and Outlier Claims

The patterns treat each record as an instance of cco:DescriptiveICE. They encode three binary relations required for reproducible anomaly reporting: correlation of evidence with a lift calculation, attachment of a baseline rate to that lift, and assertion that an outlier claim rests on at least one attribute.

### 1.1 Evidence Correlation Table

Table t_evidence_correlated_with embodies axiom evidence_correlated_with. Column id is the primary key. Column y is a foreign key into t_lift_with_baseline_rate, allowing an evidence record to reference the lift calculation it supports. A reader can join the two tables to retrieve the baseline rate attached to any given evidence identifier.

```sql
CREATE TABLE t_evidence_correlated_with (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_lift_with_baseline_rate(id)
);
```

### 1.2 Lift with Baseline Rate Table

Table t_lift_with_baseline_rate embodies axiom lift_with_baseline_rate. Column id is the primary key. Column y is a foreign key into t_evidence_correlated_with, closing the mutual reference between evidence and its derived lift. Joining on these keys yields the evidence identifier that originally supplied the observation used to compute the lift.

```sql
CREATE TABLE t_lift_with_baseline_rate (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_evidence_correlated_with(id)
);
```

| lift-02 | rate:0.037 | ev-03 |
| lift-03 | rate:0.052 | ev-01 |
| lift-04 | rate:0.029 | ev-05 |

### 1.3 Outlier Claim Attribute Table

Table t_outlier_claim_min_one_attribute embodies axiom outlier_claim_min_one_attribute. Column id is the primary key. Column y is a foreign key into t_evidence_correlated_with, ensuring every outlier claim references at least one supporting evidence record. A three-table join across outlier claim, evidence, and lift recovers the baseline rate attached to any attribute set.

```sql
CREATE TABLE t_outlier_claim_min_one_attribute (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_evidence_correlated_with(id)
);
```

## 2 Cross-Table Query Example

To answer the question “which baseline rate supports the outlier claim on temperature spike recorded 18 April 2020,” the analyst performs the following walk:

1. Select claim-01 from t_outlier_claim_min_one_attribute (y = ev-01).
2. Follow ev-01 into t_evidence_correlated_with (y = lift-03).
3. Follow lift-03 into t_lift_with_baseline_rate (x = rate:0.052).

The joined row is therefore (claim-01, attr:temp_spike, ev-01, lift-03, rate:0.052).

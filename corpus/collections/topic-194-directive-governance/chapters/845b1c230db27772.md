# Evidence Correlation Structures in Descriptive Measurement Ontologies

This chapter presents three interlinked ontological templates that formalize relationships among descriptive information content entities. The templates are realized as a minimal relational schema whose primary and foreign keys encode the slot restrictions directly. The domain chosen is laboratory measurement of cardiac CT image features, where evidence items, baseline rates, and outlier claims must be traced across multiple tables.

## 1 Evidence Correlation and Baseline Rate Templates

The first two templates capture mutual referential constraints between evidence correlation statements and statements that assert a baseline rate. Each template is expressed by a dedicated table whose foreign-key column points to the primary key of the complementary table, enforcing the existential restrictions declared in the axioms.

### 1.1 Table t_lift_with_baseline_rate

This table embodies the axiom “lift_with_baseline_rate”. Column id is the primary key. Column x stores the identifier of the DescriptiveICE that carries the baseline-rate assertion; column y stores the identifier of the evidence item with which the rate is correlated. The foreign-key constraint on y references t_evidence_correlated_with.id.

| id                  | x                       | y                       |
|---------------------|-------------------------|-------------------------|
| LBR-001             | BaselineRate:HU-450     | EC-101                  |
| LBR-002             | BaselineRate:HU-470     | EC-102                  |
| LBR-003             | BaselineRate:Vol-12.4   | EC-103                  |
| LBR-004             | BaselineRate:Vol-11.9   | EC-104                  |
| LBR-005             | BaselineRate:HU-455     | EC-105                  |

### 1.2 Table t_evidence_correlated_with

This table embodies the axiom “evidence_correlated_with”. Column id is the primary key. Column x stores the identifier of the evidence item; column y stores the identifier of the baseline-rate statement that supplies the correlation target. The foreign-key constraint on y references t_lift_with_baseline_rate.id.

| id                  | x                       | y                       |
|---------------------|-------------------------|-------------------------|
| EC-101              | Evidence:Slice-47       | LBR-001                 |
| EC-102              | Evidence:Slice-51       | LBR-002                 |
| EC-103              | Evidence:Slice-39       | LBR-003                 |
| EC-104              | Evidence:Slice-42       | LBR-004                 |
| EC-105              | Evidence:Slice-48       | LBR-005                 |
| EC-106              | Evidence:Slice-55       | LBR-001                 |

### 1.3 Table t_outlier_claim_min_one_attribute

This table embodies the axiom “outlier_claim_min_one_attribute”. Column id is the primary key. Column x stores the identifier of the DescriptiveICE that asserts an outlier; column y stores the identifier of the evidence item that supplies at least one attribute. The foreign-key constraint on y references t_evidence_correlated_with.id.

| id                  | x                       | y                       |
|---------------------|-------------------------|-------------------------|
| OCA-201             | OutlierClaim:HighHU     | EC-101                  |
| OCA-202             | OutlierClaim:LowVol     | EC-103                  |

## 2 Cross-Table Query Example

A reader can answer the multi-hop question “which outlier claim is supported by evidence correlated with baseline rate LBR-001?” by the following join path. First locate the row in t_lift_with_baseline_rate whose id equals LBR-001; its y value is EC-101. Next locate the row in t_evidence_correlated_with whose id equals EC-101. Finally locate the row in t_outlier_claim_min_one_attribute whose y equals EC-101. The joined result is the single row (OCA-201, OutlierClaim:HighHU, EC-101, Evidence:Slice-47, LBR-001, BaselineRate:HU-450).

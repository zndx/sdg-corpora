# Chapter 7: Directive Governance Models for GDPR Audit Trails

This chapter presents five relational tables that instantiate the slot structures of five OWL axioms governing lawful basis, evidence requirements, attestation, and audit processes. The schema supports multi-table joins that trace a control directive to its required evidence, the attestation that supplies that evidence, and the audit period under which the attestation is evaluated.

## 1 Table Definitions and Axiom Embodiment

### 1.1 Lawful Basis Table

The table t_gdpr_lawful_basis embodies Axiom 1 by recording pairs of classes where the first is a subclass of cco:DirectiveICE and the second supplies the lawful basis. Column id is the primary key. Column y is a foreign key that must resolve to an existing id in t_control_with_evidence_requirement, enforcing that every lawful basis is referenced by at least one control that declares an evidence requirement.

```sql
CREATE TABLE t_gdpr_lawful_basis (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_control_with_evidence_requirement(id)
);
```

### 1.2 Control with Evidence Requirement Table

The table t_control_with_evidence_requirement embodies Axiom 4. Column id is the primary key. Column y is a foreign key referencing t_gdpr_lawful_basis(id), linking each control directive to the lawful basis whose evidence it requires.

```sql
CREATE TABLE t_control_with_evidence_requirement (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_gdpr_lawful_basis(id)
);
```

### 1.4 Audit for Period Table

The table t_audit_for_period embodies Axiom 3. Column id is the primary key. Column y is a foreign key referencing t_gdpr_lawful_basis(id), associating each audit process instance with the lawful basis active during the audited interval.

```sql
CREATE TABLE t_audit_for_period (
  id VARCHAR(255),
```

## 2 Cross-Table Query Example

To determine the attestation supplied for the lawful basis referenced by control ctl_ev_03, join t_control_with_evidence_requirement to t_gdpr_lawful_basis on y = id, then join the result to t_attestation_with_supporting_evidence on t_gdpr_lawful_basis.id = t_attestation_with_supporting_evidence.y. The join yields:

- ctl_ev_03 → id_gdpr_01 (ConsentProcessing) → att_01 (ConsentLogExport) and att_07 (WithdrawalConfirmation).

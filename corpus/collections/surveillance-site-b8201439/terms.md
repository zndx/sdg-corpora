# Grounding terms

The ontology universals this collection's chapters are written around (each an sdg: class, grounded in a BFO/CCO genus).

## Surveillance Site
- **genus**: `bfo:0000040`
- **definition**: A geographically distributed physical location housing radar or sensor equipment monitored by the CMS/XA system.
- **attributes**: siteIdentifier, siteName, latitude, longitude, siteType, operationalStatus, deploymentDate
- **relations**: monitoredBy→ControlCentre, hosts→RadarStation, connectedVia→NetworkLink

## Control Centre
- **genus**: `bfo:0000040`
- **definition**: A central facility where operators supervise multiple remote surveillance sites and process monitoring data.
- **attributes**: centreIdentifier, centreName, jurisdiction, centreType, establishedDate, isPrimary
- **relations**: supervises→SurveillanceSite, runs→MonitoringApplication, connectedVia→NetworkLink

## Radar Station
- **genus**: `bfo:0000040`
- **definition**: A specific piece of radar hardware or sensor array installed at a surveillance site.
- **attributes**: radarIdentifier, radarModel, frequencyBand, maxRange, installationDate, lastMaintenanceDate, isUpgraded
- **relations**: locatedAt→SurveillanceSite, generatesDataFor→DataAcquisitionUnit, monitoredBy→ControlCentre

## Data Acquisition Unit
- **genus**: `bfo:0000040`
- **definition**: A hardware or software component responsible for collecting raw surveillance data from radar stations.
- **attributes**: acquisitionUnitId, firmwareVersion, samplingRate, dataFormat, status, lastSyncTimestamp
- **relations**: connectedTo→RadarStation, transmitsTo→NetworkLink, processedBy→ProcessingServer

## Network Link
- **genus**: `bfo:0000040`
- **definition**: A communication channel, such as a leased line or surveillance network, connecting sites and centres.
- **attributes**: linkIdentifier, linkType, bandwidth, latency, isRedundant, protocol
- **relations**: connects→SurveillanceSite, connectsTo→ControlCentre, supports→DataAcquisitionUnit

## Monitoring Event
- **genus**: `bfo:0000015`
- **definition**: A discrete occurrence or alert generated by the system indicating a change in status, fault, or operational state.
- **attributes**: eventId, eventTimestamp, eventType, severity, description, resolved, resolutionTime
- **relations**: originatesFrom→SurveillanceSite, affects→RadarStation, triggeredBy→DataAcquisitionUnit, viewedBy→ControlCentre

## Processing Server
- **genus**: `bfo:0000040`
- **definition**: A hardware or virtualized server instance responsible for processing, storing, and managing surveillance data.
- **attributes**: serverId, serverRole, osVersion, databaseType, uptime, lastHealthCheck
- **relations**: locatedIn→ControlCentre, processesDataFrom→DataAcquisitionUnit, supports→MonitoringApplication

## Monitoring Application
- **genus**: `bfo:0000040`
- **definition**: A software module or interface used by operators to visualize, filter, and manage surveillance data.
- **attributes**: appId, appName, version, interfaceType, isCustomized, lastUpdated
- **relations**: runsOn→ProcessingServer, usedAt→ControlCentre, displaysDataFrom→SurveillanceSite

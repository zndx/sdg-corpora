# Chapter 12. Measurement Provenance and Control Subclasses in Regulated Laboratory Systems

This chapter defines five ontological templates that relate process executions, descriptive information content entities, directive constraints, and column-level annotations. The templates are realized as a five-table relational schema. Primary keys identify each class instance; foreign keys encode the existential restrictions stated in the axioms. Cross-table joins recover multi-hop relations such as “which NIST control governs a measurement produced by a given laboratory run and recorded in a given column.”

## 1. Laboratory Run as Process

Axiom labrun_produces_measurement states that a laboratory run is a bfo:Process that produces at least one cco:DescriptiveICE. The single-column table below therefore contains only a primary-key identifier; each row stands for a distinct run class.

```sql
CREATE TABLE t_labrun_produces_measurement (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

| id | x |
|----|---|
| LR-001 | FoliarNutrientAssayRun |
| LR-002 | PestResidueQuantRun |
| LR-003 | SoilMicronutrientRun |
| LR-004 | WaterContaminantScreenRun |
| LR-005 | TissueHeavyMetalRun |

## 2. Descriptive Entity Sourced from Table

Axiom table_provenance_source asserts that a DescriptiveICE is sourcedFromTable some other class. Column y is a foreign key into t_measurement_with_method, establishing the table that supplied the data.

```sql
CREATE TABLE t_table_provenance_source (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_measurement_with_method(id)
);
```

| id | x | y |
|----|---|---|
| TPS-010 | SprayEfficacyTable | MWM-100 |
| TPS-011 | ResidueReportTable | MWM-101 |
| TPS-012 | MicronutrientLogTable | MWM-102 |
| TPS-013 | ContaminantMatrixTable | MWM-103 |
| TPS-014 | MetalResultArchiveTable | MWM-104 |

## 3. Measurement Linked to Method

Axiom measurement_with_method states that a DescriptiveICE is obtained viaMethod some class. Column y is a foreign key into t_table_provenance_source, closing the mutual reference between method documentation and table provenance.

```sql
CREATE TABLE t_measurement_with_method (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_table_provenance_source(id)
);
```

| id | x | y |
|----|---|---|
| MWM-100 | ICPMSResultSet | TPS-010 |
| MWM-101 | LC_MSQuantSet | TPS-011 |
| MWM-102 | AASFlameSet | TPS-012 |
| MWM-103 | GC_ECDScreenSet | TPS-013 |
| MWM-104 | ICP_OESArchiveSet | TPS-014 |

## 4. NIST 800-53 Control Subclass

Axiom nist80053_control_subclass places a DirectiveICE under a specific NIST 800-53 control. Column y references t_labrun_produces_measurement, linking the control directly to the originating laboratory run.

```sql
CREATE TABLE t_nist80053_control_subclass (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_labrun_produces_measurement(id)
);
```

| id | x | y |
|----|---|---|
| NC-200 | AC-3_AccessEnforcement | LR-001 |
| NC-201 | AU-9_ProtectionOfAuditInfo | LR-002 |
| NC-202 | CM-6_ConfigurationSettings | LR-003 |
| NC-203 | SI-7_SoftwareFirmwareIntegrity | LR-004 |
| NC-204 | SC-8_TransmissionConfidentiality | LR-005 |

## 5. Column Tag Annotation

Axiom column_tag_subclass states that a DescriptiveICE annotatesColumn some class. Column y references t_measurement_with_method, allowing a tag to be attached to any method-qualified measurement.

```sql
CREATE TABLE t_column_tag_subclass (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_measurement_with_method(id)
);
```

## 6. Multi-Hop Query Example

Question: Which NIST control governs the measurement recorded under the SprayVolumeTag that originated from laboratory run LR-001?

Walk the foreign keys:

1. CT-300.y = MWM-100  
2. MWM-100.y = TPS-010  
3. TPS-010 is linked through the measurement chain to LR-001 via the run that produced the ICPMSResultSet.  
4. NC-200.y = LR-001

Result row after join:

| column_tag | measurement_method | provenance_table | lab_run | nist_control |
|------------|--------------------|------------------|---------|--------------|
| SprayVolumeTag | ICPMSResultSet | SprayEfficacyTable | FoliarNutrientAssayRun | AC-3_AccessEnforcement |

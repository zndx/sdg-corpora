# Chapter 7: Laboratory Measurement Provenance in Controlled Research Protocols

This chapter defines five ontological templates that capture laboratory processes producing measurements, their sourcing, methods, control classifications, and column annotations. The templates are realized as a five-table relational schema supporting primary-key and foreign-key joins. All instances derive from horticulture foliar-spray protocols conducted by farmer-researchers.

## 1. Core Process and Measurement Templates

### 1.1 Laboratory Run Producing Descriptive Measurements

Axiom 1 classifies any laboratory run as a process that produces a descriptive information content entity. The table therefore stores only the run identifier and the run class; its single-column primary key supplies the foreign-key target used by downstream control classifications.

```sql
CREATE TABLE t_labrun_produces_measurement (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

| id | x |
|----|---|
| LR-001 | FoliarSprayEfficacyRun |
| LR-002 | CrashCropHealthRun |
| LR-003 | PestDamageAssessmentRun |
| LR-004 | NutrientUptakeTrialRun |
| LR-005 | DiseaseIncidenceLogRun |

### 1.2 Measurement With Associated Method

Axiom 3 classifies a descriptive information content entity that is realized via a method. The table records the measurement identifier, the measurement class, and a mandatory foreign key to a provenance source record; the foreign key permits a reader to traverse from any measurement directly to its table-level source.

```sql
CREATE TABLE t_measurement_with_method (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_table_provenance_source(id)
);
```

| id | x | y |
|----|---|---|
| MM-101 | DiseaseSeverityScore | TPS-01 |
| MM-102 | PestCountPerLeaf | TPS-02 |
| MM-103 | ChlorophyllIndex | TPS-01 |
| MM-104 | YieldPerPlotKg | TPS-03 |
| MM-105 | BrixValue | TPS-02 |

### 1.3 Table Provenance Source

Axiom 2 classifies a descriptive information content entity that is sourced from a table. The table records the provenance identifier, the provenance class, and a mandatory foreign key back to a measurement-with-method record, closing the bidirectional reference required by the axiom pair.

```sql
CREATE TABLE t_table_provenance_source (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_measurement_with_method(id)
);
```

| id | x | y |
|----|---|---|
| TPS-01 | FieldObservationLog | MM-101 |
| TPS-02 | HarvestDataSheet | MM-102 |
| TPS-03 | LaboratoryAssayReport | MM-103 |
| TPS-04 | WeatherStationExport | MM-104 |

## 2. Control and Annotation Templates

### 2.1 NIST 800-53 Control Subclass

Axiom 4 classifies a directive information content entity that references an NIST 800-53 control. The table stores the control-subclass identifier, the subclass class, and a mandatory foreign key to a laboratory-run record, thereby linking security-control requirements directly to the originating process.

```sql
CREATE TABLE t_nist80053_control_subclass (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_labrun_produces_measurement(id)
);
```

| id | x | y |
|----|---|---|
| NC-201 | AC-3AccessEnforcement | LR-001 |
| NC-202 | AU-2AuditEvents | LR-002 |
| NC-203 | CM-6ConfigurationSettings | LR-003 |
| NC-204 | SI-4SystemMonitoring | LR-004 |

### 2.2 Column Tag Subclass

Axiom 5 classifies a descriptive information content entity that annotates a column. The table stores the tag-subclass identifier, the subclass class, and a mandatory foreign key to a measurement-with-method record, allowing column-level annotations to be resolved back to the measurement that produced the column values.

```sql
CREATE TABLE t_column_tag_subclass (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_measurement_with_method(id)
);
```

| id | x | y |
|----|---|---|
| CT-301 | UnitPercent | MM-101 |
| CT-302 | CountInteger | MM-102 |
| CT-303 | Index0to100 | MM-103 |
| CT-304 | MassKg | MM-104 |
| CT-305 | DegreesBrix | MM-105 |

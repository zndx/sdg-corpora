# Laboratory Data Management: Modeling Measurement Provenance and Controls

This chapter presents five relational tables that implement a minimal LIMS schema for tracking laboratory runs, measurements, table provenance, NIST 800-53 control mappings, and column annotations. The tables embody the supplied OWL axioms and support cross-table joins that answer multi-hop questions about measurement lineage and compliance.

## 1. Core Axioms and Schema Overview

The schema directly projects the five template axioms. Each table carries a surrogate primary key in column `id`. Foreign-key columns enforce the slot restrictions stated in the Manchester syntax, enabling deterministic joins between DescriptiveICE instances and their related process or directive entities.

## 2. Table Definitions and Axiom Embodiment

### 2.1 t_labrun_produces_measurement

This table embodies AXIOM 1 (labrun_produces_measurement). Column `id` is the primary key; column `x` holds the subclass of bfo:0000015. A reader can join on `x` to locate every DescriptiveICE produced by a given lab run.

| id | x |
|----|---|
| LM001 | LabRun_FoliarNutrient |
| LM002 | LabRun_PestResidue |
| LM003 | LabRun_SoilTraceMetal |
| LM004 | LabRun_WaterContaminant |

### 2.2 t_measurement_with_method

This table embodies AXIOM 3 (measurement_with_method). Column `id` is the primary key; column `y` is a foreign key referencing t_table_provenance_source(id). The join yields the method class that produced each DescriptiveICE measurement.

| id | x | y |
|----|---|---|
| MM001 | ICP_MS_Result | TPS001 |
| MM002 | HPLC_Pesticide | TPS002 |
| MM003 | AAS_Metal | TPS003 |
| MM004 | GC_MS_Contaminant | TPS001 |
| MM005 | ICP_OES_Water | TPS004 |

### 2.3 t_table_provenance_source

This table embodies AXIOM 2 (table_provenance_source). Column `id` is the primary key; column `y` is a foreign key referencing t_measurement_with_method(id). The join recovers the source table that supplied each measurement.

| id | x | y |
|----|---|---|
| TPS001 | RawData_2023Q3 | MM001 |
| TPS002 | RawData_2023Q3 | MM002 |
| TPS003 | RawData_2023Q4 | MM003 |
| TPS004 | RawData_2023Q4 | MM005 |

### 2.4 t_nist80053_control_subclass

This table embodies AXIOM 4 (nist80053_control_subclass). Column `id` is the primary key; column `y` is a foreign key referencing t_labrun_produces_measurement(id). The join identifies the NIST control that governs each lab run.

| id | x | y |
|----|---|---|
| NC001 | AC-3_AccessEnforcement | LM001 |
| NC002 | AU-6_AuditReview | LM002 |
| NC003 | CM-6_ConfigurationSettings | LM003 |
| NC004 | SI-4_SystemMonitoring | LM004 |

### 2.5 t_column_tag_subclass

This table embodies AXIOM 5 (column_tag_subclass). Column `id` is the primary key; column `y` is a foreign key referencing t_measurement_with_method(id). The join returns the column annotation attached to each measurement.

| id | x | y |
|----|---|---|
| CT001 | Concentration_ppm | MM001 |
| CT002 | RetentionTime_min | MM002 |
| CT003 | Absorbance_AU | MM003 |
| CT004 | PeakArea | MM004 |
| CT005 | DetectionLimit | MM005 |

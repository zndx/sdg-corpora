# Laboratory Measurement Provenance and Control Annotation

This chapter defines a minimal relational schema that realizes five OWL axioms for laboratory processes, descriptive information content entities, methods, provenance, NIST controls, and column annotations. The schema supports multi-hop queries that traverse primary and foreign keys to recover full measurement context.

## 1 Scope and Axiom Mapping

The five tables below are direct projections of the supplied Manchester axioms. Each table name matches a template identifier; column positions and foreign-key constraints are fixed by the slot types. All entity references are drawn from a laboratory information management domain in which runs produce measurements, measurements carry method and provenance metadata, and selected measurements are further annotated by NIST-800-53 controls and column tags.

## 2 Tables

### 2.1 t_labrun_produces_measurement

Axiom 1 states that a laboratory run (bfo:Process) produces a descriptive information content entity. The table therefore stores the run identifier together with the measurement it yields. Column id is the primary key; column x holds the measurement reference.

| id | x |
|---|---|
| LR-001 | MEAS-1001 |
| LR-002 | MEAS-1002 |
| LR-003 | MEAS-1003 |
| LR-004 | MEAS-1004 |

### 2.2 t_measurement_with_method

Axiom 3 states that a descriptive information content entity is realized via a method. The table therefore records each measurement and its governing method. Column id is the primary key; column y is a foreign key referencing t_table_provenance_source.id.

| id | x | y |
|---|---|---|
| MEAS-1001 | M-ICP-MS | TPS-9001 |
| MEAS-1002 | M-ICP-MS | TPS-9002 |
| MEAS-1003 | M-Colorimetry | TPS-9003 |
| MEAS-1004 | M-Colorimetry | TPS-9001 |

### 2.3 t_table_provenance_source

Axiom 2 states that a descriptive information content entity is sourced from a table. The table therefore records the measurement and its originating table. Column id is the primary key; column y is a foreign key referencing t_measurement_with_method.id.

| id | x | y |
|---|---|---|
| TPS-9001 | RAW-ICP-2024-03 | MEAS-1001 |
| TPS-9002 | RAW-ICP-2024-03 | MEAS-1002 |
| TPS-9003 | RAW-COL-2024-03 | MEAS-1003 |
| TPS-9004 | RAW-COL-2024-03 | MEAS-1004 |

### 2.4 t_nist80053_control_subclass

Axiom 4 states that a directive information content entity carries an NIST-800-53 control. The table therefore links each controlled measurement to its control identifier. Column id is the primary key; column y is a foreign key referencing t_labrun_produces_measurement.id.

| id | x | y |
|---|---|---|
| NIST-80053-AC-2 | AC-2 | LR-001 |
| NIST-80053-AU-6 | AU-6 | LR-002 |
| NIST-80053-CM-6 | CM-6 | LR-003 |
| NIST-80053-SI-4 | SI-4 | LR-004 |

### 2.5 t_column_tag_subclass

Axiom 5 states that a descriptive information content entity annotates a column. The table therefore records each column tag and the measurement it annotates. Column id is the primary key; column y is a foreign key referencing t_measurement_with_method.id.

| id | x | y |
|---|---|---|
| TAG-LOD | limit_of_detection | MEAS-1001 |
| TAG-RSD | relative_standard_deviation | MEAS-1002 |
| TAG-REC | recovery_percent | MEAS-1003 |
| TAG-UNC | uncertainty_k2 | MEAS-1004 |

## 3 Cross-Join Demonstration

To recover the NIST control, method, and column tag for measurement MEAS-1001 the following mental join is performed:

- Start at t_measurement_with_method row MEAS-1001 (method M-ICP-MS, provenance TPS-9001).  
- Follow t_table_provenance_source.y = MEAS-1001 to obtain table RAW-ICP-2024-03.  
- Follow t_labrun_produces_measurement.x = MEAS-1001 to obtain run LR-001.  
- Follow t_nist80053_control_subclass.y = LR-001 to obtain control AC-2.  
- Follow t_column_tag_subclass.y = MEAS-1001 to obtain tag limit_of_detection.

Resulting joined tuple: (MEAS-1001, M-ICP-MS, RAW-ICP-2024-03, LR-001, AC-2, limit_of_detection).

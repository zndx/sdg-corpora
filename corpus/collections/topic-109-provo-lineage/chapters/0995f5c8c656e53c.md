# Measurement Provenance and Control Annotation in Laboratory Runs

This chapter defines five relational tables that instantiate the listed OWL axioms for laboratory processes producing measurements, provenance links, method associations, NIST 800-53 control mappings, and column annotations. The tables support cross-table joins that recover multi-hop facts such as the control governing a measurement produced by a given laboratory run.

## 1 Laboratory Run and Measurement Production

Axiom 1 states that a laboratory run is a process that produces a descriptive information content entity. Table t_labrun_produces_measurement therefore records each run as an entity reference in column x. The primary key is id; no foreign keys are present.

```sql
CREATE TABLE t_labrun_produces_measurement (
  id VARCHAR(255),
  x VARCHAR(255),
  PRIMARY KEY (id)
);
```

Example rows:

id | x
---|---
LR-001 | FoliarNutrientAssay-20200607
LR-002 | SoilHeavyMetalScan-20200614
LR-003 | WaterContaminantProfile-20200621
LR-004 | PlantTissueResidueTest-20200628

## 2 Measurement with Associated Method

Axiom 3 states that a descriptive information content entity is obtained via a method. Table t_measurement_with_method therefore links each measurement (x) to a method (y). The primary key is id; column y is a foreign key referencing t_table_provenance_source.id.

```sql
CREATE TABLE t_measurement_with_method (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_table_provenance_source(id)
);
```

Example rows:

id | x | y
---|---|---
M-100 | NitrateConcentration | TPS-010
M-101 | LeadPpm | TPS-011
M-102 | pHValue | TPS-012
M-103 | CadmiumPpm | TPS-013
M-104 | ZincPpm | TPS-014

## 3 Table Provenance Source

Axiom 2 states that a descriptive information content entity is sourced from a table. Table t_table_provenance_source therefore records the source table (x) for each measurement entity (y). The primary key is id; column y is a foreign key referencing t_measurement_with_method.id.

```sql
CREATE TABLE t_table_provenance_source (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_measurement_with_method(id)
);
```

Example rows:

id | x | y
---|---|---
TPS-010 | Results_Foliar_2020 | M-100
TPS-011 | Results_Soil_2020 | M-101
TPS-012 | Results_Water_2020 | M-102
TPS-013 | Results_Tissue_2020 | M-103
TPS-014 | Results_Tissue_2020 | M-104

## 4 NIST 800-53 Control Subclass

Axiom 4 states that a directive information content entity is associated with an NIST 800-53 control. Table t_nist80053_control_subclass therefore maps each directive entity (x) to a control identifier (y). The primary key is id; column y is a foreign key referencing t_labrun_produces_measurement.id.

```sql
CREATE TABLE t_nist80053_control_subclass (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_labrun_produces_measurement(id)
);
```

Example rows:

id | x | y
---|---|---
C-200 | CA-7_ContinuousMonitoring | LR-001
C-201 | SI-4_SystemMonitoring | LR-002
C-202 | AU-6_AuditReview | LR-003
C-203 | RA-5_VulnerabilityMonitoring | LR-004

## 5 Column Tag Subclass

Axiom 5 states that a descriptive information content entity annotates a column. Table t_column_tag_subclass therefore records each annotation (x) and the measurement entity it annotates (y). The primary key is id; column y is a foreign key referencing t_measurement_with_method.id.

```sql
CREATE TABLE t_column_tag_subclass (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_measurement_with_method(id)
);
```

Example rows:

id | x | y
---|---|---
TAG-300 | Unit_mg_per_L | M-100
TAG-301 | Unit_ppm | M-101
TAG-302 | Unit_pH | M-102
TAG-303 | Unit_ppm | M-103
TAG-304 | Method_ICPOES | M-104

## 6 Cross-Join Example

To determine the NIST 800-53 control and column annotation for the measurement produced by laboratory run LR-001, join t_labrun_produces_measurement to t_nist80053_control_subclass on id = y, then join t_measurement_with_method to t_column_tag_subclass on id = y. The resulting row is:

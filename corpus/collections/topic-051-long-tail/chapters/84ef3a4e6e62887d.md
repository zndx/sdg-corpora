# Modeling Menu Artifacts with Descriptive Ontologies

This chapter presents five relational tables that encode menu-item descriptions as instances of cco:DescriptiveICE and cco:Artifact. The tables are derived directly from the supplied OWL axioms and support cross-table navigation via shared entity references in the x and y columns.

## 1 Table Topic Assignment

The t_table_topic_tag table embodies AXIOM 1. Column id is the primary key; columns x and y function as foreign-key references to menu-item classes and topic classes respectively, allowing a reader to retrieve every topic that applies to a given item.

```sql
CREATE TABLE t_table_topic_tag (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

## 2 Table Provenance Source

The t_table_provenance_source table embodies AXIOM 2. Column id is the primary key; x references a descriptive class while y references the source table class, enabling verification of the originating menu for any description.

```sql
CREATE TABLE t_table_provenance_source (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

## 3 Product Price Assignment

The t_schemaorg_product_price table embodies AXIOM 3. Column id is the primary key; x references an artifact class and y its price literal, supporting direct retrieval of monetary values for any listed item.

## 6 Cross-Join Example

To determine the price and brand of a gluten-free item served at 123 MAIN ST, first select rows from t_table_topic_tag where y = 'GF', yielding x = 'TAP & BURGER SIGNATURE WINGS'. Join that x value into t_schemaorg_product_price on x to obtain y = '12.5'. A second join into t_schemaorg_product_brand on the same x yields y = 'TAP SAUCE'. A final join into t_schemaorg_place_address confirms y = '123 MAIN ST'. The resulting tuple is therefore (TAP & BURGER SIGNATURE WINGS, 12.5, TAP SAUCE, 123 MAIN ST).

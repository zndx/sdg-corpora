# Audit Trail Modeling for Claim Support in Regulatory Documentation

This chapter defines five ontological templates that capture how artifacts and processes support descriptive claims under governance constraints. The templates are realized as a five-table relational schema drawn from audit-trail records in a GDPR compliance repository. Primary keys are uniformly named `id`; the sole foreign-key relationship links lawful-basis records to signed attestations. Cross-table queries therefore traverse at most one hop, yet still permit verification that every claim-supporting entity is grounded in an attested directive.

## 1. Ontological Templates and Their Relational Projections

### 1.1 Trace Supports Claim
The table `t_trace_supports_claim` embodies axiom 1. Column `id` is the primary key; column `x` holds the class that realizes the trace. A reader can therefore retrieve every class asserted to support a descriptive information content entity by selecting the `x` values.

| id | x |
|----|---|
| trc-001 | DataRetentionTrace |
| trc-002 | AccessLogTrace |
| trc-003 | ConsentWithdrawalTrace |
| trc-004 | CrossBorderTransferTrace |
| trc-005 | PurposeLimitationTrace |

### 1.2 Attestation Signed By
The table `t_attestation_signed_by` embodies axiom 2. Column `id` is the primary key; column `x` records the person who signed the attestation. All subsequent references to signed attestations resolve through this key.

| id | x |
|----|---|
| att-100 | Tom Gordon |
| att-101 | IKPONMWOSA O. OLOMU |
| att-102 | Bryan Mi |

### 1.3 GDPR Lawful Basis
The table `t_gdpr_lawful_basis` embodies axiom 3. Column `id` is the primary key; column `x` names the directive information content entity; column `y` is a foreign key referencing `t_attestation_signed_by(id)`. A single join therefore yields both the lawful basis and its signatory.

## 2. Cross-Join Demonstration

To determine which signatory attested the lawful basis for a consent directive, execute the following mental join:

```sql
SELECT l.x AS directive, a.x AS signatory
FROM   t_gdpr_lawful_basis l
JOIN   t_attestation_signed_by a ON l.y = a.id
WHERE  l.x = 'ConsentDirective';
```

Result row: directive = ConsentDirective, signatory = Tom Gordon. The same pattern extends to any other lawful-basis row, confirming that every directive is anchored to a signed attestation.

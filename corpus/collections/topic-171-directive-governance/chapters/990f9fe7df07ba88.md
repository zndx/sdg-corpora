# Directive Governance for Audit Processes

This chapter specifies the relational tables that realize five axioms for audit, attestation, and requirement structures. The tables support cross-table joins that resolve multi-hop queries over periods, signers, conductors, evidence, and directive targets.

## 1. Table t_audit_for_period

This table embodies AXIOM 1 by recording each audit process and the period to which it applies. Column id is the primary key. Column x references the audit instance; column y is a foreign key to a period identifier and is required. A reader can join this table to t_audit_conducted_by on x to retrieve the person responsible for an audit in a stated period.

| id          | x           | y            |
|-------------|-------------|--------------|
| AFP-001     | AUD-2014Q2  | PER-2014Q2   |
| AFP-002     | AUD-2014Q3  | PER-2014Q3   |
| AFP-003     | AUD-2015Q1  | PER-2015Q1   |
| AFP-004     | AUD-2015Q2  | PER-2015Q2   |
| AFP-005     | AUD-2016Q4  | PER-2016Q4   |

## 2. Table t_attestation_min_one_signer

This table embodies AXIOM 2 by asserting that each listed process instance carries at least one signer. Column id is the primary key. Column x references the attested process. A reader can join this table to t_verification_min_one_evidence on x to confirm that an attested process also produced required evidence.

| id          | x           |
|-------------|-------------|
| AMS-001     | AUD-2014Q2  |
| AMS-002     | AUD-2014Q3  |
| AMS-003     | AUD-2015Q1  |
| AMS-004     | AUD-2015Q2  |
| AMS-005     | AUD-2016Q4  |
| AMS-006     | AUD-2014Q2  |

## 3. Table t_audit_conducted_by

This table embodies AXIOM 3 by linking each audit process to its conducting person. Column id is the primary key. Column x references the audit instance. A reader can join this table to t_audit_for_period on x to obtain both the period and the conducting person for a given audit.

| id          | x           |
|-------------|-------------|
| ACB-001     | AUD-2014Q2  |
| ACB-002     | AUD-2014Q3  |
| ACB-003     | AUD-2015Q1  |
| ACB-004     | AUD-2015Q2  |
| ACB-005     | AUD-2016Q4  |

## 4. Table t_verification_min_one_evidence

This table embodies AXIOM 4 by recording each verification process together with at least one evidence item it produces. Column id is the primary key. Column x references the verification process; column y is a foreign key to an evidence identifier and is required. A reader can join this table to t_attestation_min_one_signer on x to verify that a signed process also satisfies the evidence requirement.

| id          | x           | y            |
|-------------|-------------|--------------|
| VME-001     | AUD-2014Q2  | EV-LOG-042   |
| VME-002     | AUD-2014Q3  | EV-LOG-051   |
| VME-003     | AUD-2015Q1  | EV-LOG-063   |
| VME-004     | AUD-2015Q2  | EV-LOG-072   |
| VME-005     | AUD-2016Q4  | EV-LOG-089   |
| VME-006     | AUD-2014Q2  | EV-LOG-043   |

## 5. Table t_requirement_equiv_specifies_target

This table embodies AXIOM 5 by capturing directive instances that specify a target and apply to a subject. Column id is the primary key. Column x references the directive; columns y and z are required foreign keys to the specified item and the subject of application, respectively. A reader can join this table to t_audit_for_period on y to determine which audit periods satisfy a given requirement.

| id          | x           | y            | z            |
|-------------|-------------|--------------|--------------|
| RET-001     | REQ-014     | PER-2014Q2   | SUBJ-MUNI    |
| RET-002     | REQ-014     | PER-2014Q3   | SUBJ-MUNI    |
| RET-003     | REQ-015     | PER-2015Q1   | SUBJ-HHS     |
| RET-004     | REQ-016     | PER-2015Q2   | SUBJ-HHS     |
| RET-005     | REQ-017     | PER-2016Q4   | SUBJ-SCHL    |

## 6. Cross-join example

To answer the query “which person conducted the audit for period PER-2014Q2 and which evidence was produced,” join t_audit_for_period to t_audit_conducted_by on x, then to t_verification_min_one_evidence on x:

- t_audit_for_period row AFP-001 supplies x = AUD-2014Q2 and y = PER-2014Q2.
- t_audit_conducted_by row ACB-001 supplies the same x and therefore the conducting person.
- t_verification_min_one_evidence rows VME-001 and VME-006 supply the same x and therefore evidence identifiers EV-LOG-042 and EV-LOG-043.

The joined result set contains the period, the conducting person, and the two evidence items for the single audit instance.

# Chapter 4: Directive Information Content Entities in Planning Compliance

This chapter presents five relational tables that encode OWL axioms for artifacts bearing postal addresses, directive information content entities that specify targets, and associated verification, enforcement, and attestation processes. The schema supports multi-hop queries across primary and foreign keys to retrieve compliance chains for municipal planning records.

## 1 Schemaorg Place Address Table

The table t_schemaorg_place_address embodies AXIOM 1 by recording artifacts that possess a postal address. Column id is the primary key; column y is a foreign key referencing t_requirement_equiv_specifies_target.id, enabling direct lookup of the directive that governs the addressed artifact.

```sql
CREATE TABLE t_schemaorg_place_address (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_requirement_equiv_specifies_target(id)
);
```

## 2 Requirement Equiv Specifies Target Table

The table t_requirement_equiv_specifies_target embodies AXIOM 2 by capturing classes equivalent to DirectiveICE that specify a target and apply to a given class. Column id is the primary key; columns y and z are foreign keys referencing t_schemaorg_place_address.id, supporting joins that recover both the specified target and the application scope.

```sql
CREATE TABLE t_requirement_equiv_specifies_target (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  z VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_schemaorg_place_address(id)
);
```

## 3 Requirement Min One Verification Table

The table t_requirement_min_one_verification embodies AXIOM 3 by asserting that each DirectiveICE instance must be verified by at least one artifact. Column id is the primary key; column y is a foreign key referencing t_schemaorg_place_address.id, allowing verification status to be retrieved via address linkage.

```sql
CREATE TABLE t_requirement_min_one_verification (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_schemaorg_place_address(id)
);
```

| ver_021 | Resin seal verification | addr_001 |

## 4 Policy Min One Enforcer Table

The table t_policy_min_one_enforcer embodies AXIOM 4 by requiring each DirectiveICE to be enforced by at least one artifact. Column id is the primary key; column y is a foreign key referencing t_schemaorg_place_address.id, permitting enforcement actor retrieval through address joins.

```sql
CREATE TABLE t_policy_min_one_enforcer (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_schemaorg_place_address(id)
);
```

## 5 Attestation With Supporting Evidence Table

The table t_attestation_with_supporting_evidence embodies AXIOM 5 by linking processes to supporting evidence artifacts. Column id is the primary key; column y is a foreign key referencing t_schemaorg_place_address.id, enabling evidence chain reconstruction across addresses.

```sql
CREATE TABLE t_attestation_with_supporting_evidence (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id),
  FOREIGN KEY (y) REFERENCES t_schemaorg_place_address(id)
);
```

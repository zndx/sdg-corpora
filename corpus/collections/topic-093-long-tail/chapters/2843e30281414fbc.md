# Chapter 7: Directive Governance Structures for Land-Use Artifacts

This chapter presents five axioms that formalize directive information content entities and their mandatory relations to owners, verifiers, enforcers, checks, and postal addresses. The axioms are projected into a five-table relational schema whose foreign-key constraints enable multi-hop queries over municipal planning records.

## 1 Ontology Axioms and Schema Projection

Five axioms drawn from the cco and sdg namespaces define the required minimum cardinalities. Each axiom is realized by one table whose column types and constraints are fixed by the slot signatures. Primary keys are synthetic identifiers; foreign keys enforce the existential restrictions stated in the Manchester syntax.

### 1.1 t_control_min_one_owner

The table embodies Axiom 2: every directive information content entity must have at least one owner of type cco:Person. Column id is the primary key; column x stores the directive class.

| id | x |
|----|---|
| ctl-001 | SpecialExceptionAmendment |
| ctl-002 | VarianceApplication |
| ctl-003 | SitePlanReview |
| ctl-004 | ConditionalUsePermit |
| ctl-005 | RezoningPetition |

### 1.2 t_schemaorg_place_address

The table embodies Axiom 1: an artifact (here a land-use directive) is related to exactly one postal address. Column id is the primary key; column y is a foreign key referencing t_control_min_one_owner.id.

## 2 Cross-Join Demonstration

To retrieve the verification address, enforcement address, and check address for the directive owned by ctl-001, the following mental join is performed:

```
t_control_min_one_owner.id = ctl-001
→ t_schemaorg_place_address.y = ctl-001 → addr-101
→ t_requirement_min_one_verification.y = addr-101 → StormwaterManagementPlan
→ t_policy_min_one_enforcer.y = addr-101 → SetbackOrdinance
→ t_constraint_min_one_check.y = addr-101 → ImperviousSurfaceLimit
```

The resulting joined row is: (ctl-001, SpecialExceptionAmendment, addr-101, 1900 W Grand Chute Blvd, StormwaterManagementPlan, SetbackOrdinance, ImperviousSurfaceLimit).

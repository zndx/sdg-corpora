# Chapter 7: Directive Governance Structures in Municipal Compliance Systems

This chapter defines five tables that implement OWL axioms for artifactual places, directive information content entities, and their minimum-cardinality relations to owners, verifiers, enforcers, and checks. The schema supports cross-table queries that trace ownership of a directive to the address at which verification, enforcement, or constraint checking occurs.

## 1. Axiom-to-Table Mapping

Each table directly projects one Manchester axiom. Primary keys are synthetic identifiers. Foreign keys encode the existential restrictions stated in the axioms.

### 1.1 t_control_min_one_owner

Axiom 2 states that every instance of a directive information content entity must have at least one owner that is a person. The table therefore stores only the directive class; ownership cardinality is enforced by the downstream foreign-key references that require a valid owner identifier.

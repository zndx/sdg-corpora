# Relational Representation of Audit Ontologies for Outlier Claims

This chapter defines four tables that instantiate the supplied OWL axioms for descriptive information content entities, supporting traces, and datasets under audit. The tables are populated with instances drawn from a financial-statement audit trail in which reported line items are examined for outliers. All foreign-key relationships follow the deterministic projections of the axioms; cross-table joins therefore recover multi-hop facts such as the trace that supports a given outlier claim on a dataset under audit.

## 1. Table Definitions and Axiom Mappings

### 1.1 t_trace_supports_claim
Axiom 2 states that any individual of class X is a process (bfo:0000015) that supports some descriptive information content entity. The table therefore records only the existence of such a trace; its single-column primary key supplies the foreign-key target for dependent claim tables.

| id | x |
|----|---|
| trc-001 | proc-audit-042 |
| trc-002 | proc-audit-043 |
| trc-003 | proc-audit-044 |
| trc-004 | proc-audit-045 |
| trc-005 | proc-audit-046 |

### 1.2 t_outlier_claim_basic
Axiom 3 asserts that an individual of class X is itself a descriptive information content entity. The table stores only the claim identifier; its primary key may be referenced by attribute-bearing claims.

| id | x |
|----|---|
| clm-010 | outlier-revenue-Q1 |
| clm-011 | outlier-expense-Q1 |
| clm-012 | outlier-asset-Q1 |
| clm-013 | outlier-liability-Q1 |
| clm-014 | outlier-cash-Q1 |

### 1.3 t_outlier_claim_min_one_attribute
Axiom 1 requires every descriptive information content entity of this subclass to possess at least one attribute set; the foreign key y therefore references a row in t_trace_supports_claim. The primary key id uniquely identifies each attributed claim.

| id | x | y |
|----|---|---|
| attr-100 | outlier-revenue-Q1 | trc-001 |
| attr-101 | outlier-expense-Q1 | trc-002 |
| attr-102 | outlier-asset-Q1 | trc-003 |
| attr-103 | outlier-liability-Q1 | trc-001 |
| attr-104 | outlier-cash-Q1 | trc-004 |

### 1.4 t_dataset_under_audit
Axiom 4 states that an artifact X is under audit by some process. The table records each dataset identifier together with the audit process that examines it; its primary key may be joined to claim tables via the shared x values.

| id | x |

| dst-200 | dataset-consolidated-2013Q1 |
| dst-201 | dataset-consolidated-2013Q2 |
| dst-202 | dataset-consolidated-2013Q3 |
| dst-203 | dataset-consolidated-2013Q4 |

## 2. Cross-Join Demonstration

To recover the trace supporting an attributed outlier claim on a dataset under audit, execute the following mental join sequence. Start with attr-100 in t_outlier_claim_min_one_attribute; its foreign key y resolves to trc-001 in t_trace_supports_claim, whose x value is proc-audit-042. The same x value appears in t_dataset_under_audit for dst-200, confirming that the revenue outlier claim on the 2013Q1 consolidated dataset is supported by audit process proc-audit-042.

Joined row (attr-100, trc-001, dst-200):  
id=attr-100, x=outlier-revenue-Q1, y=trc-001, trace_x=proc-audit-042, dataset_id=dst-200

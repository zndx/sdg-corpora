# Audit Claim Ontologies in Relational Form

This chapter presents four tables that realize the axioms outlier_claim_basic, trace_supports_claim, dataset_under_audit and outlier_claim_min_one_attribute. The tables are populated with instances drawn from an audit trail for condensed consolidated balance-sheet data. Primary and foreign keys enable the reader to traverse from a descriptive claim to its supporting trace and from a dataset to the process that places it under audit.

## 1 Schema Realization of the Axioms

### 1.1 t_outlier_claim_basic
The table embodies axiom 3. Column id is the primary key. Column x holds the identifier of an individual that is a subclass of cco:DescriptiveICE. A reader can retrieve every basic outlier claim by selecting the single table.

| id | x |
|----|---|
| OCB-001 | BalanceSheetOutlier-0313 |
| OCB-002 | ReceivableVariance-0313 |
| OCB-003 | CashEquivalentDiscrepancy-0313 |
| OCB-004 | OtherReceivableAnomaly-0313 |
| OCB-005 | AssetReclassificationNote-0313 |

### 1.2 t_trace_supports_claim
The table embodies axiom 2. Column id is the primary key. Column x holds the identifier of a process (bfo:0000015) that supports some cco:DescriptiveICE. Every row therefore records an audit trace that can be referenced by more complex claim tables.

| id | x |
|----|---|
| TSC-001 | RevaluationTrace-2013Q1 |
| TSC-002 | BankConfirmationTrace-2013Q1 |
| TSC-003 | IntercompanyEliminationTrace-2013Q1 |
| TSC-004 | DepreciationReviewTrace-2013Q1 |
| TSC-005 | ProvisionAssessmentTrace-2013Q1 |
| TSC-006 | ForeignExchangeTrace-2013Q1 |

### 1.3 t_dataset_under_audit
The table embodies axiom 4. Column id is the primary key. Column x holds the identifier of an artifact (cco:Artifact) that participates in some audit process. The table therefore enumerates the financial-statement datasets placed under review.

| id | x |
|----|---|
| DUA-001 | CondensedBalanceSheet-20130331 |
| DUA-002 | InterimIncomeStatement-20130331 |
| DUA-003 | CashFlowCondensed-20130331 |
| DUA-004 | EquityMovementSchedule-20130331 |

### 1.4 t_outlier_claim_min_one_attribute
The table embodies axiom 1. Column id is the primary key. Column x holds the identifier of a descriptive information content entity that must possess at least one attribute set. Column y is a foreign key referencing t_trace_supports_claim.id, thereby guaranteeing that every such claim is linked to at least one supporting trace.

| id | x | y |
|----|---|---|
| OCM-001 | BalanceSheetOutlier-0313 | TSC-001 |
| OCM-002 | ReceivableVariance-0313 | TSC-002 |
| OCM-003 | CashEquivalentDiscrepancy-0313 | TSC-003 |
| OCM-004 | OtherReceivableAnomaly-0313 | TSC-004 |
| OCM-005 | AssetReclassificationNote-0313 | TSC-005 |
| OCM-006 | BalanceSheetOutlier-0313 | TSC-006 |

## 2 Cross-Table Query Example

To determine which supporting trace backs the outlier claim “BalanceSheetOutlier-0313” that appears in the dataset “CondensedBalanceSheet-20130331”, the reader performs the following mental join. First locate the row in t_outlier_claim_min_one_attribute where x equals “BalanceSheetOutlier-0313”; the foreign key y yields TSC-001 and TSC-006. Next read the corresponding rows in t_trace_supports_claim to obtain the process identifiers “RevaluationTrace-2013Q1” and “ForeignExchangeTrace-2013Q1”. The same claim identifier also appears in t_outlier_claim_basic, confirming that the entity satisfies the minimal DescriptiveICE requirement. The resulting joined view contains the triple (DUA-001, OCM-001, TSC-001) together with (DUA-001, OCM-006, TSC-006).

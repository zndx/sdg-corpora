# Directive Governance in Audit Trail Systems

This chapter defines five core ontological patterns for directive governance and demonstrates their implementation as a relational schema for audit compliance records. The model supports traceability from requirements through controls, attestations, verifications, and risk addressing, using entity references that permit cross-table joins on shared identifiers.

## 1. Table Structures

This table embodies AXIOM 1, recording processes that carry supporting evidence. Column id is the primary key; columns x and y are entity references with no declared foreign-key constraints within the table.

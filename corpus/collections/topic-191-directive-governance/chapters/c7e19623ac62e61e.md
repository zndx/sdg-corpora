# Chapter 4: Directive Controls, Attestations and Evidence Production in Governance Audit Trails

This chapter defines five relational tables that implement the core axioms of directive governance. The tables record controls, requirements, attestations, verifications and risk-addressing constraints for the Birmingham Federation of Maintained Nursery Schools. All rows conform to the Manchester axioms supplied in Section 2; primary-key and foreign-key columns enable deterministic cross-table joins.

## 1 Scope and Table Overview

The schema supports queries that trace a control to its required evidence, the verification process that produced that evidence, and the risk class the control is permitted to address. Five tables are defined. Each table name corresponds directly to one axiom template. Column order follows the deterministic slot order given in the axiom schemas.

## 1.1 Table t_control_with_evidence_requirement

This table embodies axiom 2: every control (X) is an instance of cco:DirectiveICE that requires at least one evidence class (Y). Column id is the primary key; columns x and y are entity references with no foreign-key constraint in this table.

```sql
CREATE TABLE t_control_with_evidence_requirement (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

## 2 Cross-Join Example

Question: Which risk class is addressed by the control that requires the evidence produced by verification V003?

Walk the links:  
- Row V003 in t_verification_produces_evidence states that verification “HRComplianceCheck” produces “TrainingRecord”.  
- Row C003 in t_control_with_evidence_requirement states that control “PreventStrategyAttestation” requires “TrainingRecord”.  
- Row T003 in t_control_only_addresses_threat_class states that “PreventStrategyAttestation” addresses only “Radicalisation”.

Joined result row:  
(PreventStrategyAttestation, TrainingRecord, Radicalisation)

The same pattern can be extended across all five tables to answer further multi-hop queries such as “which target class is covered by a requirement whose evidence is attested by process A005”.

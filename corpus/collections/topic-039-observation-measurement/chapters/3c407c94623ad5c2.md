# Chapter 7: Relational Encoding of HIPAA and PCI DSS Directive Classes

This chapter defines five tables that instantiate the supplied OWL axioms for DirectiveICE and DescriptiveICE subclasses. The tables support primary-key and foreign-key joins that trace safeguard classes to baseline-rate descriptors and onward to requirement classes.

## 1 t_hipaa_safeguard_technical table

Axiom 1 states that each row represents a subclass of cco:DirectiveICE that hipaaSafeguard some technical control class. Column id is the primary key. Column y is a foreign key that must resolve to an id in t_lift_with_baseline_rate, allowing a reader to retrieve the baseline rate attached to any technical safeguard instance.

| id     | x                          | y       |
|--------|----------------------------|---------|
| HST001 | AccessControlDirective     | LBR001  |
| HST002 | AuditLogDirective          | LBR002  |
| HST003 | EncryptionInTransit        | LBR003  |
| HST004 | SessionTimeoutDirective    | LBR004  |
| HST005 | IntegrityCheckDirective    | LBR005  |

## 2 t_lift_with_baseline_rate table

Axiom 2 states that each row represents a subclass of cco:DescriptiveICE that hasBaselineRate some measured class. Column id is the primary key. Column y is a foreign key that resolves to an id in t_hipaa_safeguard_technical, enabling direct retrieval of the technical safeguard whose baseline rate is described.

## 6 Cross-table query example

Question: which PCI DSS requirement shares a baseline-rate descriptor with the technical safeguard “AccessControlDirective”?

Execution path:  
1. Locate HST001 in t_hipaa_safeguard_technical (y = LBR001).  
2. Locate LBR001 in t_lift_with_baseline_rate.  
3. Locate PCI002 in t_pci_dss_requirement (y = LBR001).

Joined row:  
HST001 | AccessControlDirective | LBR001 | BaselineRateAccess | PCI002 | Requirement_2_Defaults

The same LBR001 row also joins to HSA002, demonstrating a three-table path from a technical safeguard through its baseline rate to both an administrative safeguard and a PCI DSS requirement.

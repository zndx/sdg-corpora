# Audit Trail Descriptive Entities in Corporate Governance

This chapter specifies two ontological templates that classify descriptive information content entities observed at events and maps them to a four-table relational schema for audit trails at Sunland Group Ltd ACN 063 429 532.

## 1 Ontology Axioms

### 1.1 claim_observed_by_event
Axiom 1 states that any class X is a subclass of cco:DescriptiveICE and stands in the relation sdg:observedAt to some bfo:0000015. The template therefore captures claims whose identity is fixed by an observation event.

### 1.2 metric_observed_by_event
Axiom 2 states the identical restriction for metric classes. The template therefore captures quantitative metrics whose identity is likewise fixed by an observation event.

## 2 Relational Implementation

Four tables realize the templates inside an audit-trail schema. Primary keys are single-column identifiers. Foreign-key values appear in the x column of each axiom table and in the subject_id column of t_audit_event, permitting direct equi-joins on event identity.

t_audit_subject stores the entities under audit. Its subject_id column is the primary key; every row corresponds to a distinct auditable unit referenced by later events.

## 3 Cross-Join Demonstration

To retrieve the claim class and metric class recorded for subject “Sunland Group Ltd” on 2018-08-01, join t_audit_subject to t_audit_event on subject_id, then join both axiom tables on event_id:

- subject S001 → event E001 (subject_id)
- event E001 → claim C001 and metric M001 (x)

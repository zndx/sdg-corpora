# Chapter 7: DirectiveICE Subclasses for Regulatory Compliance

This chapter defines five subclasses of cco:DirectiveICE that capture distinct regulatory requirements and safeguards. Each subclass is projected to a dedicated relation whose rows instantiate the corresponding Manchester axiom. The five relations share a uniform column structure in which the y column holds class references that may be resolved across tables, enabling multi-hop retrieval of linked compliance statements.

## 1 Ontological Axioms and Their Relational Projections

Five axioms are introduced. Each axiom asserts that a class X is a subclass of cco:DirectiveICE and is existentially restricted by a single object property to another class Y. The axioms are realized by the tables described in sections 1.1–1.5. In every table the column id is the primary key; the column y functions as a logical foreign key whose values may be matched against id or x values in any of the five tables.

### 1.1 Table t_pci_dss_requirement

This table embodies axiom pci_dss_requirement. Column id is the primary key. Column y references a PCI DSS control class that may be joined to y values in the HIPAA or ISO tables when the same control identifier appears.

```sql
CREATE TABLE t_pci_dss_requirement (
  id VARCHAR(255),
  x VARCHAR(255),
  y VARCHAR(255) NOT NULL,
  PRIMARY KEY (id)
);
```

| pdr1 | FirewallConfiguration    | 1.1        |

| pdr3 | AccessLogging            | 10.2       |
| pdr4 | StrongAuthentication     | 8.2        |
| pdr5 | VulnerabilityScanning    | 11.2       |

### 1.2 Table t_hipaa_safeguard_technical

This table embodies axiom hipaa_safeguard_technical. Column id is the primary key. Column y references a technical safeguard class that can be joined on equality with y values from t_pci_dss_requirement or t_iso27001_annexa_subclass.

```sql
CREATE TABLE t_hipaa_safeguard_technical (
  id VARCHAR(255),
```

## 2 Cross-Table Retrieval Example

To retrieve every directive that references control identifier “3.4”, execute the following mental join across t_pci_dss_requirement and t_hipaa_safeguard_technical on the y column:

- Row pdr2 (x = EncryptionAtRest, y = 3.4) from t_pci_dss_requirement
- Row hst5 (x = EncryptionStandard, y = 3.4) from t_hipaa_safeguard_technical
